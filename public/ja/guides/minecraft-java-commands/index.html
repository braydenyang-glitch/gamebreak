Java 版でコマンドを使う

自分のワールドでコマンドを準備します。

Minecraft マインクラフト · Java

Unverified · Java · 対象パッチの実機検証なし

Quick answer

ワールド設定で Allow Commands を有効にし、チャットで / から始まるコマンドを入力します。

Before you start

PC の Java 版と自分のテスト用ワールド。

Steps

  1. 新規シングルプレイでは、作成前に Allow Commands を有効にします。
  2. 既存ワールドは World Options を確認します。旧バージョンでは Open to LAN → Allow Cheats を使う場合があります。
  3. チャットを開き、/ から入力してゲーム内の候補を確認します。

許可されたコマンドが受け付けられます。

拒否されたらサーバー管理者に権限を確認します。

他の人のサーバーでは管理者の許可が必要です。メニュー名はバージョンで異なります。
