対応する音骸のメイン能力を変更する

変更器を使う前に対象と能力を確認します。

鳴潮 · 鳴潮 · 通常探索とメニュー

Unverified · Data Modification · Ver.2.3 の資料

Quick answer

Terminal → Data Bank → Data Modification を開きます。

Before you start

Modifier と未強化の星 5 音骸。

Steps

  1. 使う共鳴者と目標能力を先に決めます。
  2. Terminal → Data Bank → Data Modification を開きます。
  3. 対応する未強化の星 5 音骸を選びます。
  4. 第 1 メインステータスの候補を選びます。
  5. 選択と費用を確認して確定します。
  6. 変更後の音骸を確認します。自動でロックされます。

選んだ第 1 メインステータスが反映されます。

選べなければレア度と強化済みかを確認します。この機能はサブ能力の変更ではありません。

公式 URL を示していますが、本文は現行ページからでなく保存版で確認しました。実機未検証です。
