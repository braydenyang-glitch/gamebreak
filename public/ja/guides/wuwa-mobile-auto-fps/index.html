Auto FPS でモバイルの負荷を抑える

適切な画質を選び、通常プレイで試します。

鳴潮 · 鳴潮 · 通常探索とメニュー

Unverified · モバイル画質設定 · Ver.1.4 の資料

Quick answer

推奨 Graphics Quality から始め、必要なら Auto FPS を使います。

Before you start

モバイル版と Graphics 設定。

Steps

  1. Settings → Graphics → Graphics Quality を開きます。
  2. 端末推奨の画質から始めます。
  3. 高負荷時に自動で下げたい場合は Auto FPS をオンにします。
  4. 以前不安定だった短い経路を試します。
  5. 別の設定を変える前に応答と見やすさを比較します。

同じ試行で端末に合う設定を比較できます。

高負荷時は画質や上限 FPS が下がる場合があります。まだ不安定なら低い設定で再試行し、万能な修正とは考えません。

出典確認のみで実機未検証です。現在の画面表示を優先します。
