運命で光円錐を絞り込む

装備の能力を比較しやすくします。

崩壊：スターレイル · 装備管理

Unverified · 光円錐フィルター · Ver.2.1 の資料

Quick answer

光円錐を運命で絞り込み、選んだ装備の能力を読みます。

Before you start

バッグと所有している光円錐。

Steps

  1. バッグの光円錐一覧を開きます。
  2. フィルターで調べたい運命を選びます。
  3. 強化・装備する前に能力と発動条件を比較します。
  4. 所有品が見えなくなったらフィルターを解除します。

選んだ運命の一覧を表示・解除できます。

紛失と判断する前に全フィルターを解除します。

運命フィルターは Ver.2.1 の資料に記載されています。レア度だけで最適装備を決めるランキングではありません。

Honkai: Star Rail · Version2.1 system changes
