PC のエラー 134 でファイルを検証する

再インストール前にランチャーで確認します。

グランド・セフト・オートV · PC · Rockstar Games Launcher 管理のインストール

Unverified · PC · Rockstar Games Launcher 管理のインストール

Quick answer

公式手順ではインストール済みファイルの整合性を検証します。

Before you start

エラー 134 と Rockstar Launcher 管理の GTA V。

Steps

  1. GTA V を閉じ、Rockstar Games Launcher にログインします。
  2. Settings を開きます。
  3. My installed games の GTA V を選びます。
  4. Verify Integrity を実行し、完了を待ちます。
  5. 完了表示後にもう一度起動します。

検証が終わり、起動エラーが解消したか確認できます。

一覧にない場合はインストールを管理するランチャーの手順を使います。続く場合は削除を繰り返さず記録してサポートへ相談します。

対処の一例で、すべての起動失敗を直す保証はありません。
