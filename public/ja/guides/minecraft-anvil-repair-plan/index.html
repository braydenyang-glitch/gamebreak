金床で道具を修理・命名する

素材を使う前に経験値費用を確認します。

Minecraft マインクラフト · Java / Bedrock · 金床修理

Unverified · Java / Bedrock · 金床修理

Quick answer

金床作業を繰り返すと、後の費用が上がります。

Before you start

金床、傷んだ道具、対応素材、経験値レベル。

Steps

  1. 安定したブロック上に金床を置いて開きます。
  2. 最初の枠に傷んだ道具を入れます。
  3. 修理素材か同種の道具を加えます。
  4. 必要なら同じ操作で名前も変えます。
  5. 完成品、耐久値、必要レベルを確認します。
  6. 費用に納得してから取り出します。

確認した耐久値と名前の品になります。

結果がなければ同種か確認します。過去の作業で費用が上がるため確定前に比較します。

エンチャントの互換性も必要で、すべての組み合わせが使えるとは限りません。
