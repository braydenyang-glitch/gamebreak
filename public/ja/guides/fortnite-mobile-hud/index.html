モバイルの HUD 配置を調整する

タッチ操作を 1 つずつ変えます。

フォートナイト · バトルロイヤル · ネイティブモバイルのタッチ操作

Unverified · 配信元のモバイル HUD 編集への案内

Quick answer

プロフィール → メニュー → HUD Layout Tool で編集画面を開きます。

Before you start

タッチ操作のモバイル版。

Steps

  1. 右上のプロフィール画像を押します。
  2. 左下の三本線メニューを開きます。
  3. 下の方の HUD Layout Tool を選びます。
  4. 画面の操作で届きにくいボタンを 1 つ変えます。
  5. 現在の表示に従い適用します。
  6. 静かな場所で試し、視界を塞ぐなら修正します。

ボタンへ届き、画面も見やすくなります。

プロフィールのメニューへ戻って入口を確認します。複数悪化したら以前へ戻し、1 つずつ変えます。

出典は入口を確認するものです。1 項目ずつ試す手順は提案で、編集画面のラベルは変わる場合があります。
