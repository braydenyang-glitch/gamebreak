冒険ランク 45・50 の上限を解除する

経験値稼ぎの前に突破任務を確認します。

原神 · 冒険ランク 45／50 の突破任務

Unverified · 冒険ランク 45／50 の突破任務

Quick answer

必要な突破を終えると、蓄積した冒険経験が反映されます。

Before you start

冒険ランク 45 または 50 と対応任務。

Steps

  1. 現在が冒険ランク 45 か 50 か確認します。
  2. 任務一覧で突破任務を探します。
  3. 45 は突破・三、50 は突破・四を選びます。
  4. 遺跡を攻略する突破目標に従います。
  5. 挑戦完了後、ランクと蓄積経験値を確認します。

対応任務を終えると上限が解除されます。

経験値だけ増える場合は突破が未完了です。現在ランクと任務番号を合わせます。

資料で説明されたランク 45 と 50 のケースのみを扱います。
