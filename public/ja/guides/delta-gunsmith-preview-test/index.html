Quick answer

元の構成を記録し、変更を 1 つ試してから適用を決めます。

Before you start

Gunsmith と射撃場。

Steps

  1. Gunsmith で元の構成を記録します。
  2. 対応するアタッチメントを 1 つ変えます。
  3. 必要に応じ Preview Mode の Calibrate を使います。
  4. 射撃場で距離を揃えて扱いやすさを試します。
  5. Gunsmith へ戻ります。資料の手順では試用構成が保持されます。
  6. 適用するか選び、出撃前に最終装備を確認します。

扱いやすさを試して構成を選べます。

戻って違う構成なら適用状態を確認します。付かない部品は対応と条件を見ます。

比較手順であり、最強ランキングではありません。調整値や地域機能は現在のクライアントで確認します。
