PC のストーリーを Enhanced へ移す

ダウンロード前に一度限りの移行を確認します。

グランド・セフト・オートV · ストーリー · PC Legacy → Enhanced

Unverified · Rockstar の PC 移行手順 · コンソール移行は対象外

Quick answer

Legacy でアップロードし、保存内容を確認してから Enhanced でダウンロードします。

Before you start

両 PC 版と正しく連携した Rockstar アカウント。

Steps

  1. 目的の PC プラットフォームと正しい Rockstar アカウントが連携済みか確認します。
  2. Legacy で Pause → Game → Upload Save Game を開きます。
  3. 対象のストーリーセーブを選び、アップロードします。
  4. 成功の表示を待ちます。
  5. Enhanced で Pause → Game → Download Save Game を開きます。
  6. 成功するとそのアカウントの移行枠を使うため、対象を確認して確定します。
  7. 完了後、読み込んだ進行を確認します。

Enhanced で目的の進行が読み込まれます。

アップロードは 90 日間で、期限後は再アップロードが必要な場合があります。移行後の同期はなく、コンソールのセーブは対象外です。

アカウントごとにアップロードは 1 件です。ダウンロード成功後は追加のストーリー移行ができません。資格制限がある場合もあります。
