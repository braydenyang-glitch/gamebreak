役割に合う位置を選ぶ

分類を出発点にして立ち位置を考えます。

ブロスタ · ブロスタ · 標準クライアント

Unverified · 配信元サポート確認日 2026-10-20

Quick answer

クラスとマップを見て、攻撃に合う経路を選びます。

Before you start

所持キャラクターと能力の説明。

Steps

  1. キャラクター画面左上のクラスを読みます。
  2. 距離、接近、遮蔽物のどれが必要か確認します。
  3. その攻撃を生かせる経路を選びます。
  4. 投擲なら越せる遮蔽物、狙撃なら距離を確保します。
  5. サポートは味方へ能力が届く位置にいます。
  6. 倒されたら全装備を替える前に立ち位置を見直します。

その位置が役割に合う理由を説明できます。

クラスは大まかな分類なので個別能力も読みます。支援できなければ単独で追わず味方と動きます。

出典確認のみで実機未検証です。現在の画面表示を優先します。
