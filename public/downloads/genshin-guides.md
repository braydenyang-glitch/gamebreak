## Find your next quest objective

Genshin Impact · Quest navigation · PC / Mobile / Console

Source checked: 2026-10-06. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Patch not playtested

Open your quest list, select the quest, and turn on navigation.

Before you start: A quest already in your quest list.

1. Open the quest list. On the default PC controls, press J.
2. Select the quest you want to follow and enable its navigation option.
3. Check the map marker and the direction shown in the game. Some quests require finding clues instead of following a marker.

Success check: The selected objective is shown for navigation.

Troubleshooting: Read the objective text if there is no marker. It may ask you to investigate clues.

Button names can vary by language and control layout.

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Exploration mechanic · build untested

Check the statue’s healing reserve, recovery percentage and individual character settings.

Before you start: An activated statue and a character below full HP.

1. Return to single-player to rule out Co-Op recovery restrictions.

## Build a weapon-material farming plan

Genshin Impact · Weapon upgrades · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
General weapon-upgrade workflow

Check the exact missing material before choosing a farming activity.

Before you start: An owned weapon and access to its upgrade screen.

1. Open the weapon upgrade screen and note the missing materials and Mora.
2. For ascension drops, check the relevant Domain of Forgery and its daily schedule.
3. Use the Crafting Bench if you already own lower-rarity materials from the same family.
4. For enemy drops, track the required enemy with the Adventurer’s Handbook.
5. Prepare enhancement ore through the Blacksmith; use Expeditions to gather supporting resources.
6. If Mora is the blocker, choose a Blossom of Wealth, commissions or available quests. Return and review the upgrade cost.

Success check: Your selected upgrade has a clear source for every missing resource.

Troubleshooting: Wrong domain reward: Check today’s rotation before spending Resin. Enough enemy drops, but upgrade still blocked: Review the separate ore, ascension-material and Mora requirements.

Domain rotations and recipes should be read in your current client. This is a resource workflow, not a recommended weapon ranking.

Sources: [HoYoverse Help · Weapon upgrade materials](https://support.hoyoverse.com/hc/en-us/articles/50333964005913-How-can-I-farm-materials-to-upgrade-my-weapons)

## Remove a quest that blocks Co-op

Genshin Impact · Co-op access after unlock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Quest and event restrictions

The multiplayer warning can name the quest that must be completed.

Before you start: An account where Co-op has already been unlocked.

1. Choose the multiplayer icon or attempt to enter Co-op.
2. Read the warning and record the quest name it identifies.
3. Open the quest list and finish that blocking quest or required stage.
4. If an event or challenge is active, finish the current portion.
5. Leave any event-vendor scene, teleport elsewhere and retry Co-op.
6. If access remains blocked, send Support the error, quest progress and a screenshot through the help interface.

Success check: The blocking warning disappears and the multiplayer menu becomes available.

Troubleshooting: The same quest is still named: Check whether its current stage is fully completed. No named quest or a different error: Capture the exact message; this guide does not diagnose account or network restrictions.

This addresses temporary quest/event blocks, not the initial Co-op unlock or every possible connection error.

Sources: [HoYoverse Help · Co-op restrictions](https://support.hoyoverse.com/hc/en-us/articles/50333905596953-Unable-to-Access-Co-op-Mode)

## Start Temporary Acclimatization

Genshin Impact · Chenyu Vale / Fontaine · World Quest · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Quest-specific prerequisites

Complete the required Chenyu and Fontaine quests, then speak with Woliu at Yilong Wharf.

Before you start: Access to Chenyu Vale and Fontaine.

1. Check progress in Chenyu’s Blessings of Sunken Jade.
2. Finish its required part, Qiaoying of the Sacred Mountain.
3. Near the Opera Epiclese in Fontaine, check the quest In Expert Company? (II).
4. Complete In Expert Company? (II); merely accepting it is insufficient.
5. Travel to Yilong Wharf in Chenyu Vale.
6. Find Woliu near the pavilion and speak with her to start Temporary Acclimatization.

Success check: Temporary Acclimatization begins and its objective appears.

Troubleshooting: Woliu offers no quest: Recheck both prerequisite completions, including part II in Fontaine. At the wrong harbour: The start is Yilong Wharf in Chenyu Vale, not the Opera Epiclese.

This guide covers unlocking the quest only; it is not a walkthrough of every later objective.

Sources: [HoYoverse Help · Temporary Acclimatization](https://support.hoyoverse.com/hc/en-us/articles/50333940506777-Unable-to-Start-the-World-Quest-Temporary-Acclimatization)

Daily commission reward system

5. Return after each 30 Resin used and claim available commission rewards.
6. Stop counting commission rewards after the daily total reaches four.

Success check: The commission reward counter increases after a claim.

## Build a beginner Hyperbloom team

Genshin Impact · Overworld · standard Hyperbloom · PC / Mobile / Console

Source checked: 2026-10-25. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Standard Dendro reactions · documented in Version 3.0

Combine Hydro and Dendro to create Dendro Cores, then hit those cores with Electro to trigger Hyperbloom.

Before you start: Owned characters able to apply Hydro, Dendro and Electro.

1. Choose one owned character for each element: Hydro, Dendro and Electro.
2. Read their skills and identify which attacks apply those elements.
3. Apply Hydro and Dendro to a normal enemy to create a Dendro Core.
4. Use an Electro attack that reaches the core and watch for Hyperbloom.
5. For a comfortable beginner team, use the remaining slot for healing or shielding if the first three characters do not provide it.

Success check: You can produce Hyperbloom and explain each teammate’s job.

Troubleshooting: No Hyperbloom? Check that a core formed and the Electro attack actually reached it.

The fourth-slot suggestion is GameBreak’s beginner planning advice. This is not a current endgame ranking or a Lunar-Bloom guide. Special character talents can change reactions.

Sources: [HoYoverse · Version 3.0 Dendro reaction introduction](https://www.hoyoverse.com/en-us/news/102755)
