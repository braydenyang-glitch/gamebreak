## Craft a fishing rod and time the catch

Minecraft · Java / Bedrock · basic fishing · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · basic fishing

Reel in when the bobber dips underwater.

Before you start: Three sticks, two string, a crafting table and water.

1. Place sticks diagonally from bottom-left to top-right in the crafting grid.
2. Put string in the two remaining right-column slots and take the rod.
3. Stand by water and use the rod to cast.
4. Watch the floating bobber until it sinks.
5. Use the rod again promptly to reel in.
6. Check the catch, then cast again if needed.

Success check: A caught item is pulled toward you.

Troubleshooting: Check the two troubleshooting cases below.

This covers basic catching, not treasure-farm requirements or guaranteed loot.
