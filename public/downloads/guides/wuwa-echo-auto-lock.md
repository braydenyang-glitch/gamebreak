## Protect useful Echo drops with an auto-lock plan

Wuthering Waves · Wuthering Waves · Data Bank / Echo Management · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Echo Management documented in Version 2.5

Create an Auto-Lock plan in Data Bank → Data Merge → Echo Management.

Before you start: Echo Management unlocked and a clear idea of the stats you want to keep.

1. Open Data Bank, then Data Merge and Echo Management.
2. Create a plan for Echoes you want to keep.
3. Set quality, COST, Sonata Effect and Mainstat criteria as needed.
4. Enable the intended plan and check any other active plans.
5. Obtain a new Echo and inspect whether its lock matches the rule.
6. Adjust overly broad criteria before adding an Auto-Discard plan.

Success check: A matching new Echo receives the intended lock.

Troubleshooting: Unexpected lock? More than one plan may be active. Lock and discard both match? The documented priority is to lock the Echo.

Auto-Discard marks an Echo for discard. Review marked items before performing a separate consuming action.
