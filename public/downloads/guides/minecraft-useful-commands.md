## Set the time or weather with a command

Minecraft · Java / Bedrock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Shared Java / Bedrock syntax · build untested

Use /time set day for daylight or /weather clear for clear weather. The tool below creates these simple commands.

Before you start: Your own test world with commands enabled, or operator permission.

1. Choose your edition and the change you want in the command builder below.
2. Copy the command, open in-game chat and paste it including the leading slash.
3. Send it and check the chat response and world.

Success check: The time or weather changes and chat accepts the command.

Troubleshooting: “Unknown command” can mean missing permission. Use the matching edition’s setup guide below.

Commands require permission. Enabling cheats in Bedrock permanently disables achievements in that world.
