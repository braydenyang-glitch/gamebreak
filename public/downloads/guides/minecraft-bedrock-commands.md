## Enable commands in Bedrock Edition

Minecraft · Bedrock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Bedrock · patch not playtested

In your single-player world’s settings, open Game and enable Allow Cheats.

Before you start: A Bedrock test world where you accept losing achievements.

1. Open the world settings and select the Game section.
2. Turn on Allow Cheats. This permanently disables achievements for that world, even if you turn it off later.
3. Open chat and enter a command beginning with /. Use the in-game suggestions for valid syntax.

Success check: Chat accepts a permitted command.

Troubleshooting: Confirm you are in Bedrock; Java settings and permissions differ.

Make sure you are following Bedrock instructions. Java commands can use different syntax.
