## Move items between two chests with a hopper

Minecraft · Java / Bedrock · container automation · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · container automation

A hopper pulls from above and pushes toward its outlet.

Before you start: Two chests and one hopper.

1. Place the destination chest with room above it.
2. Sneak while placing the hopper so its outlet faces that chest.
3. Place the input chest directly above the hopper.
4. Put one test item in the input chest.
5. Open the destination chest and check the transfer.
6. Add the remaining items only after the test works.

Success check: The test item moves into the destination chest.

Troubleshooting: Check the two troubleshooting cases below.

A powered hopper is locked. This simple layout does not sort different item types.
