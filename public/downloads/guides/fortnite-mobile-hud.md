## Find and test the mobile HUD layout tools

Fortnite · Battle Royale · native mobile touch interface · Mobile

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Publisher mobile HUD editor entry path

Profile → menu → HUD Layout Tool opens the layout editor.

Before you start: The mobile game with touch controls.

1. Tap your profile picture in the upper-right corner.
2. Open the three-line menu at the lower left.
3. Choose HUD Layout Tool near the end of that menu.
4. Use the editor’s on-screen options to change one hard-to-reach control.
5. Apply the layout using its current prompts.
6. Test in a quiet area and revise if the control blocks your view.

Success check: You can reach the changed control and still see the action.

Troubleshooting: Wrong settings page? Return to the profile menu and look for HUD Layout Tool. Several controls feel worse? Restore the previous layout and change only one at a time.

The help article verifies the entry path. The one-change test is editorial advice; editor labels may vary.
