## Set up a simple log-to-planks Crafter

Minecraft · Java / Bedrock · Crafter available · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · Crafter available

Disable unused slots and collect from the Crafter’s front.

Before you start: A Crafter, logs, a button and an output container with hopper.

1. Place the Crafter with its front facing the collection area.
2. Open its grid and disable eight slots, leaving one active.
3. Put a log into the active slot.
4. Place a collection hopper below the front output, leading into storage.
5. Supply one redstone pulse with a button.
6. Check that planks reach the collection area before adding more logs.

Success check: A pulse crafts planks and the front output is collected.

Troubleshooting: Check the two troubleshooting cases below.

The one-button test is an editorial starter setup, not a fully timed factory.
