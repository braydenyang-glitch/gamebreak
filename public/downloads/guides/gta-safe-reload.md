## Make a separate save before troubleshooting

Grand Theft Auto V · Story mode · PC / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Story Mode · build untested

Use the phone’s Quick Save and choose a separate slot before testing a mission workaround.

Before you start: Story Mode with saving available.

1. In Story Mode, open the in-game phone and select Quick Save.
2. Choose a separate save slot; keep your earlier save.
3. After saving, load the new slot if the workaround calls for a reload.

Success check: A separate save entry exists with the expected progress.

Troubleshooting: If saving is unavailable, wait until the current activity ends.

This is a recovery step, not a guaranteed mission fix. It does not apply to GTA Online.

Sources: [Rockstar Support · Quick Save workaround](https://support.rockstargames.com/articles/2anfBi4NMr3QqtUMeum51b/what-to-do-if-no-further-missions-are-showing-up-in-gtav-story-mode)
