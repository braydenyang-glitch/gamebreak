## Repair and rename a tool with an anvil

Minecraft · Java / Bedrock · anvil repair · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · anvil repair

Repeated anvil work raises later costs.

Before you start: An anvil, a damaged tool, compatible materials and XP levels.

1. Place the anvil on a stable block and open it.
2. Put the damaged tool in the first input.
3. Add its repair material or another matching tool.
4. If needed, rename it during the same operation.
5. Review the output, durability and XP cost.
6. Take the result only when the tradeoff is acceptable.

Success check: The output has the reviewed durability and name.

Troubleshooting: Check the two troubleshooting cases below.

Enchantment compatibility still matters; this does not guarantee every pair can combine.
