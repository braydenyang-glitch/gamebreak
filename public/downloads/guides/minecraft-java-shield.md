## Craft and use a Java shield

Minecraft · Java · PC

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java shield controls · default mouse input

Craft the shield, face the attack and hold Use Item to block.

Before you start: A crafting table, six planks and one iron ingot.

1. Open a crafting table’s 3 × 3 grid.
2. Place six planks in a Y pattern, with one iron ingot in the top-middle gap.
3. Collect the shield and hold it for a simple first test.
4. Face the direction of the incoming attack.
5. Hold Use Item, normally right-click in Java, to raise it.
6. Check durability afterwards; repair with planks at an anvil when appropriate.

Success check: The shield raises and blocks a blockable attack from the front.

Troubleshooting: Damage still gets through: Check facing; not every attack is blockable and axes can disable shields. Shield does not raise: Check Java’s Use Item binding and that you are holding the shield.

These are Java mouse controls. Bedrock blocking controls differ. Repair cost and remaining durability should be checked in-game.
