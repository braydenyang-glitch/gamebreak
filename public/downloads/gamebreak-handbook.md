## Elemental reactions

Genshin Impact · Combat

Combine elements to change what an attack does.

An elemental reaction happens when compatible elements meet. For example, Pyro and Hydro can cause Vaporize, while Pyro and Cryo can cause Melt. These reactions increase the damage of the attack that triggers them.

The order of the elements matters. Read the character’s skill description and watch which element is already on the enemy before switching characters. A reaction team needs reliable element application, not simply four different elements.

- Vaporize: Pyro + Hydro
- Melt: Pyro + Cryo
- Look for: Element icons on the target

Source checked 2026-10-15

## Adventure Rank and World Level

Genshin Impact · Progression

Your account progress and world difficulty are different things.

Adventure Rank tracks account progress and unlocks systems, quests and challenges. It is separate from an individual character’s level. Adventure EXP moves you toward the next rank.

World Level affects enemies and rewards in the open world. Some increases require an Ascension Quest. If fights suddenly feel harder after a World Level increase, review your main team’s equipment and upgrades before moving on.

- Adventure Rank: Account progression
- World Level: Open-world difficulty and rewards
- Character level: Upgraded separately

## Artifact slots and stats

Genshin Impact · Equipment

Match the main stat to your character’s job.

Artifacts add stats to a character. The slots are Flower, Plume, Sands, Goblet and Circlet. Each piece has a main stat and additional smaller stats, commonly called substats.

A matching set can add a bonus, but the stats still need to suit the character. Compare the old and new piece before replacing it. Read the character’s abilities to see whether their important effects use ATK, HP, DEF or another stat.

- Equipment: Artifacts
- Compare: Main stat, substats and set

## Toughness and Weakness Break

Honkai: Star Rail · Combat

Match the weakness icons to reduce Toughness.

Toughness is the extra gauge shown above an enemy’s HP. Attacks with a matching weakness type normally reduce it. Emptying the gauge triggers Weakness Break, which can delay the enemy and apply an effect based on the breaking attack’s type.

Some enemies lock their Toughness or have several layers. Some character abilities also change the normal rules. Inspect the enemy and the battle effects when matching the weakness icon does not seem to work.

- Belongs to: Enemies
- Basic method: Attack with a listed weakness type
- Not the same as: HP

Source checked 2026-10-15

## Shared Skill Points

Honkai: Star Rail · Combat

Plan your next turn before spending the team’s points.

Skill Points are a team resource used by many Skills. Normal Basic Attacks generally restore a point, while many Skills spend one. Abilities can have different costs, generate extra points or use special resources.

Look at the shared counter before choosing an action. If a teammate needs a healing or damage Skill next, consider using a Basic Attack now. Read the current ability description rather than assuming every character follows the standard pattern.

## Crafting and the recipe book

Minecraft · Basics

Use recipes to find both the ingredients and their layout.

In Java and Bedrock, crafting turns materials into new items. Your inventory has a small crafting grid; placing and using a crafting table gives you a larger one. A crafting table is made from wooden planks.

Open the recipe book and select the item you want. The recipe shows the required supplies and arrangement. Red ingredient highlights indicate missing materials. Use the recipe book for your edition instead of assuming every recipe is identical.

- Editions: Java and Bedrock
- Start with: Wood → planks → crafting table
- Tool: In-game recipe book

## Beds and respawn points

Minecraft · Survival

Set a safe return point before exploring far away.

In both Java and Bedrock, a new world has a world spawn point. Using a bed in the Overworld can set a personal respawn point. Look for the confirmation message after using the bed.

Moving the bed does not automatically move your respawn point. Use it again in its new safe location. If the old respawn point becomes unusable, you may return to world spawn after death, so record your base location too.

- Editions: Java and Bedrock
- Bed scope: Overworld
- Remember: Use the bed again after moving it

## Reading coordinates

Minecraft · Exploration

Save your base’s X, Y and Z before leaving.

Coordinates describe your position with three values: X, Y and Z. Y is height; X and Z locate you across the world. Recording a location makes it easier to return to a base or meet a friend.

Java Edition shows coordinates in the F3 debug interface; its layout can vary by version. Bedrock Edition has a Show Coordinates world setting. Use instructions for the edition you are actually playing.

- Java: F3 debug interface
- Bedrock: Show Coordinates world setting
- Y value: Height

## Health, hunger and food

Minecraft · Survival

Watch the food meter as well as your hearts.

In ordinary Java and Bedrock Survival play, hearts show health and drumsticks show hunger. Physical activity uses food. Running out of food can cause damage, with the result depending on difficulty.

Eating restores hunger, and a sufficiently full hunger bar supports natural healing under normal world rules. Carry food before mining or travelling. Check your difficulty and game rules if health behaves differently from a standard Survival world.

- Editions: Java and Bedrock
- Hearts: Health
- Drumsticks: Hunger

## Rush warning cues

Roblox · DOORS · Enemies

Find cover when the room warns you.

In ordinary Hotel encounters, flickering lights can warn that Rush is approaching. Locate an available hiding spot and listen for its approach. Rush is dangerous when it passes through the rooms.

Wait for the immediate threat to pass, then leave the hiding place. Do not use a single memorised countdown for every room: progression and modifiers can affect hiding rules.
