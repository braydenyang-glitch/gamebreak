## Turn on commands in Java Edition

Minecraft · Java · PC

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java · patch not playtested

Enable Allow Commands in your world settings, then open chat and start a command with /.

Before you start: Java Edition on PC; use your own test world.

1. For a new single-player world, enable Allow Commands before creating it.
2. In an existing world, check World Options for Allow Commands. Older versions may use Open to LAN → Allow Cheats instead.
3. Open chat, type a command beginning with /, and use the in-game suggestions.

Success check: Chat accepts a permitted command.

Troubleshooting: If access is denied on a server, ask its owner about permissions.

On someone else’s server, you need the owner’s permission. Menu names differ between versions.

## Prepare a safe first-night shelter

Minecraft · Java / Bedrock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · Overworld survival basics

Before dark, enclose a small shelter, light it with torches and use a bed if you have one.

Before you start: A Survival world, building blocks and ideally sticks and coal.

1. Collect building blocks while it is daylight.
2. Close off a small shelter with blocks so mobs cannot reach you.
3. Craft torches using sticks and coal, then light the shelter.
4. If available, place a bed in your protected Overworld shelter and sleep when permitted.

Success check: You have a lit enclosed shelter before night.

Troubleshooting: If mobs can enter, inspect openings before expanding the base.

This is an Overworld beginner routine. Lighting reduces ordinary dark-area spawns; it does not remove every danger or secure an open entrance.

## Craft and use a Java shield

Minecraft · Java · PC

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java shield controls · default mouse input

Craft the shield, face the attack and hold Use Item to block.

Before you start: A crafting table, six planks and one iron ingot.

1. Open a crafting table’s 3 × 3 grid.
2. Place six planks in a Y pattern, with one iron ingot in the top-middle gap.
3. Collect the shield and hold it for a simple first test.
4. Face the direction of the incoming attack.
5. Hold Use Item, normally right-click in Java, to raise it.
6. Check durability afterwards; repair with planks at an anvil when appropriate.

Success check: The shield raises and blocks a blockable attack from the front.

Troubleshooting: Damage still gets through: Check facing; not every attack is blockable and axes can disable shields. Shield does not raise: Check Java’s Use Item binding and that you are holding the shield.

These are Java mouse controls. Bedrock blocking controls differ. Repair cost and remaining durability should be checked in-game.

## Use a Blast Furnace for metal processing

Minecraft · Java / Bedrock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Blast Furnace · ordinary Survival mechanics

A Blast Furnace processes eligible metal items faster; it does not replace every furnace recipe.

Before you start: Five iron ingots, three smooth stone, one furnace and suitable fuel.

1. Use a crafting table and put three smooth stone across the bottom row.
2. Place the furnace in the centre and fill the remaining five slots with iron ingots.
3. Place the completed Blast Furnace in your base.
4. Open it and add an eligible ore or metal equipment item to process.
5. Add fuel and wait for the progress indicator to finish.
6. Take the output. Use a normal furnace for recipes the Blast Furnace does not accept.

Success check: The selected eligible input produces its smelted output.

Troubleshooting: Nothing starts: Check both fuel and whether the input belongs in a Blast Furnace. Fuel does not last longer: It burns fuel faster as it works faster; fuel per item is not improved.

Official documentation describes double processing speed. Modded recipes can change eligibility.

## Navigate back toward world spawn

Minecraft · Java / Bedrock · Overworld · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Ordinary compass; excludes lodestone and recovery compasses

Follow the red needle in the Overworld, while choosing a safe route around obstacles.

Before you start: Four iron ingots, one redstone dust and a crafting table.

1. Put redstone dust in the crafting grid’s centre.
2. Place an iron ingot above, below, left and right of it.
3. Take the ordinary compass and enter the Overworld.
4. Observe the red needle and turn toward its direction.
5. Travel safely in that direction, checking the needle as you move.
6. Use known landmarks near world spawn to locate your destination.

Success check: You move back toward the world’s spawn area.

Troubleshooting: Compass does not lead to my house: It targets world spawn; sleeping in a bed does not make it a home locator. Needle behaves strangely: A normal compass is not a reliable route guide in other dimensions.

This is not a pathfinding tool. A base away from spawn needs a separate navigation method.

## Prepare a diamond-mining trip

Minecraft · Java / Bedrock · post-Caves & Cliffs terrain · PC / Mobile / Console

Source checked: 2026-10-25. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · post-1.18 terrain principles; current patch not tested

Bring an iron pickaxe and use coordinates to explore deep Overworld terrain. Do not follow old Y=11 advice as a universal rule.

Before you start: An iron pickaxe, food, torches, blocks and a route back to your base.

1. Record your base coordinates before leaving.
2. In Java, use F3 and read XYZ. In Bedrock, enable Show Coordinates under the world’s Game settings.
3. Bring an iron pickaxe: a stone pickaxe is not the upgrade step used to collect diamonds.
4. Descend with a staircase or another route you can retrace. Watch for open drops and lava.
5. Search deep terrain, including buried blocks. The post-1.18 distribution puts more diamond ore lower down and reduces exposed-air ore.
6. Mine discovered diamond ore with your iron pickaxe and return before your supplies run out.

Success check: You find diamond ore, collect its drop with a suitable pickaxe and can retrace your route.

Troubleshooting: Check your world generation/version and search beyond visible cave walls. No route guarantees a diamond deposit.

This gives preparation and distribution principles, not a measured best Y-level or diamonds-per-hour claim. Modpacks and older terrain can differ.
