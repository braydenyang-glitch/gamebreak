## Reduce avoidable connection delay

Fortnite · Battle Royale · Network troubleshooting · PC / Console / Mobile

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Publisher network help

Pause heavy network traffic and compare the same playlist under similar conditions.

Before you start: An online match and access to the device network and Game settings.

1. Stop large downloads, uploads and streams on the connection.
2. Use a wired connection if your device supports it.
3. Open Settings → Game → Language and Region.
4. Review Subregion Preference if this option is available in your region.
5. Try the same playlist again and compare responsiveness.
6. Keep the change only if it helps; expect a possible matchmaking wait trade-off.

Success check: You can tell whether connection changes improve the delay.

Troubleshooting: Still delayed? Internet routing or server congestion can remain outside your control. Longer queue after a preference change? Reconsider that preference; it can affect matchmaking.

This targets network delay; it is not a promised fix for low frame rate.
