## Change an eligible Echo’s main stat

Wuthering Waves · Wuthering Waves · standard overworld and menus · PC / Console / Mobile

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Data Modification documented in Version 2.3

Open Terminal → Data Bank → Data Modification.

Before you start: A Modifier and an unenhanced five-star Echo.

1. Choose the Resonator and stat goal before opening the tool.
2. Open Terminal → Data Bank → Data Modification.
3. Select an eligible unenhanced five-star Echo.
4. Choose the offered target for its first main stat.
5. Review the selection and cost before confirming.
6. Inspect the changed Echo; modification locks it automatically.

Success check: The Echo shows the selected first main stat.

Troubleshooting: Echo not selectable? Check its rarity and whether it has already been enhanced. Wanted a substat change? This documented feature changes the first main stat.
