## Remove a quest that blocks Co-op

Genshin Impact · Co-op access after unlock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Quest and event restrictions

The multiplayer warning can name the quest that must be completed.

Before you start: An account where Co-op has already been unlocked.

1. Choose the multiplayer icon or attempt to enter Co-op.
2. Read the warning and record the quest name it identifies.
3. Open the quest list and finish that blocking quest or required stage.
4. If an event or challenge is active, finish the current portion.
5. Leave any event-vendor scene, teleport elsewhere and retry Co-op.
6. If access remains blocked, send Support the error, quest progress and a screenshot through the help interface.

Success check: The blocking warning disappears and the multiplayer menu becomes available.

Troubleshooting: The same quest is still named: Check whether its current stage is fully completed. No named quest or a different error: Capture the exact message; this guide does not diagnose account or network restrictions.

This addresses temporary quest/event blocks, not the initial Co-op unlock or every possible connection error.
