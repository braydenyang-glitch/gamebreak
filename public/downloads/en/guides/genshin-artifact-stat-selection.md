## Plan an artifact before spending Sanctifying Elixir

Genshin Impact · Artifact creation with Sanctifying Elixir · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Artifact creation with Sanctifying Elixir

The creation feature can set a main stat and two substats.

Before you start: Access to artifact creation and enough displayed materials.

1. Write down the artifact set and slot your character needs.
2. Choose the required main stat before selecting substats.
3. Open the artifact creation feature and match those choices.
4. Review its current Elixir cost and all selected stats.
5. Create only after confirming the preview.
6. Inspect the result before spending further enhancement materials.

Success check: The created artifact matches the selected set and chosen stats.

Troubleshooting: Check the two troubleshooting cases below.

No best-build ranking or fixed Elixir price is claimed.
