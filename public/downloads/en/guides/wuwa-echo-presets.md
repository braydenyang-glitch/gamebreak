## Save and compare an Echo preset

Wuthering Waves · Wuthering Waves · Echo Assembly · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Echo Preset documented in Version 2.1

Save Current Setup in Echo Preset, then compare before applying another.

Before you start: Owned Echoes and access to Echo Assembly.

1. Open the Resonator’s Echo Assembly interface.
2. Select the Echo Preset icon at the bottom right.
3. Choose Current Setup and Save As Preset.
4. Give the setup a name that explains its purpose.
5. Select a saved preset and expand the attribute comparison.
6. Use Apply only when you want that lineup on the current Resonator.

Success check: The named preset appears and its applied lineup matches your intention.

Troubleshooting: Wrong stats? Compare the saved preset against Current Setup before applying. Expected a weapon change? This feature saves an Echo lineup; inspect weapon equipment separately.

A saved preset preserves a choice; it does not establish that the build is optimal.
