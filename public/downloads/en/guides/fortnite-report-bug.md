## Report a Battle Royale bug

Fortnite · Battle Royale · PC / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Battle Royale · menu not tested

Open the game menu → Report → Submit a report → A bug, then check the screenshot before sending.

Before you start: The issue visible in-game, ideally before it disappears.

1. Open the game menu and select the three-line menu, then Report and Submit a report.
2. Choose A bug and the closest reason; use Other if none fits.
3. Check the screenshot, retake it if needed, then choose Continue and Accept.

Success check: The reporting flow reaches its confirmation.

Troubleshooting: Recreate the issue safely if the screenshot does not show it.

Epic recommends reporting while the issue is visible. Submitting a report does not confirm that the bug is fixed.
