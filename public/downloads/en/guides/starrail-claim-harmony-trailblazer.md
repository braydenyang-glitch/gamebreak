## Find the Harmony Trailblazer claim

Honkai: Star Rail · After Jarilo-VI mission The Return · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
After Jarilo-VI mission The Return

The claim moved from the removed event to Switch Path.

Before you start: The Return completed and an unclaimed Harmony Trailblazer.

1. Confirm that The Return is complete in Jarilo-VI.
2. Open the Trailblazer’s character screen.
3. Enter the Switch Path interface.
4. Claim the Harmony / Imaginary path if it is still unclaimed.
5. Select that path and review its equipment before battle.

Success check: Harmony / Imaginary is available in the Trailblazer’s paths.

Troubleshooting: Check the two troubleshooting cases below.
