## Adjust graphics for a smoother DOORS run

Roblox · DOORS · Roblox platform · DOORS preparation · PC / Mobile

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Roblox platform · graphics setting

In Roblox Settings, switch Graphics Mode to Manual and lower Graphics Quality if performance is poor.

Before you start: Access to the Roblox in-experience menu.

1. While in an experience, open the Roblox menu and select Settings.
2. Set Graphics Mode to Manual.
3. Move Graphics Quality left for performance or right for visual detail.
4. Resume and compare the same scene; use Automatic if you prefer device-managed quality.

Success check: The selected quality setting is applied and performance can be compared.

Troubleshooting: If responsiveness is unchanged, avoid assuming graphics are the only cause.

This adjusts Roblox rendering. It does not fix every network delay or DOORS gameplay issue.
