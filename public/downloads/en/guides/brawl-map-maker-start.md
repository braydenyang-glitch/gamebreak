## Build a small practice map

Brawl Stars · Brawl Stars · standard client · Map Maker · Mobile

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Publisher support checked 20 October 2026

Choose a mode and theme in Map Maker, place a simple layout, and save.

Before you start: Map Maker access; the help page requires 1,000 total Trophies.

1. Open Map Maker from the game menu.
2. Create a map with a clear name, mode and theme.
3. Start with a simple route between the important areas.
4. Place objects from the selection at the bottom of the screen.
5. Check that obstacles do not make the layout confusing.
6. Save the map before leaving the editor.

Success check: Your named map is saved and ready for further testing.

Troubleshooting: Map Maker locked? Check the Trophy requirement. No room for another map? The documented save limit is five maps.
