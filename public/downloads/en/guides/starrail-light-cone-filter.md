## Find Light Cones by Path

Honkai: Star Rail · Equipment management · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Light Cone filtering · documented in2.1

Use the Light Cone filter to narrow the list by Path, then read the selected cone's ability.

Before you start: Access to Inventory and owned Light Cones.

1. Open Inventory and the Light Cone list.
2. Open its filter and choose the Path you want to inspect.
3. Compare the displayed abilities and conditions before enhancing or equipping a cone.
4. Clear the filter if an owned cone disappears from the list.

Success check: The list shows the selected Path and can be reset.

Troubleshooting: Clear all filters before assuming an item has been lost.

Path filtering is documented in Version2.1. This guide does not rank cones or claim that rarity alone determines the best choice.
