## Change one uncomfortable control

Fortnite · Battle Royale · keyboard or controller · PC / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Publisher control configuration help

Choose the keyboard or controller tab in Settings.

Before you start: Access to Settings and a keyboard or supported controller.

1. Select Battle Royale in the lobby so its settings are available.
2. Open the menu and select the settings gear.
3. Choose the keyboard-arrow icon or the gamepad icon.
4. On PC with a controller, check the selected controller configuration.
5. Change one uncomfortable action and apply the setting.
6. Test that action in a quiet area and keep a note of the old binding.

Success check: The intended button performs the action comfortably.

Troubleshooting: Keyboard tab missing on Switch? That tab is not supported there. Wrong options showing? Return to the intended game mode and input-device tab.
