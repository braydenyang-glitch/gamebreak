## Turn on commands in Java Edition

Minecraft · Java · PC

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java · patch not playtested

Enable Allow Commands in your world settings, then open chat and start a command with /.

Before you start: Java Edition on PC; use your own test world.

1. For a new single-player world, enable Allow Commands before creating it.
2. In an existing world, check World Options for Allow Commands. Older versions may use Open to LAN → Allow Cheats instead.
3. Open chat, type a command beginning with /, and use the in-game suggestions.

Success check: Chat accepts a permitted command.

Troubleshooting: If access is denied on a server, ask its owner about permissions.

On someone else’s server, you need the owner’s permission. Menu names differ between versions.
