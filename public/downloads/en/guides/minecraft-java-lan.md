## Open a Java world to nearby friends

Minecraft · Java · PC

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java Edition · LAN hosting

Load your Java world, choose Open to LAN, review guest settings and start the LAN session.

Before you start: Java clients on one local network and compatible game versions.

1. Use Java Edition and make sure joining players are on the same local network.
2. Load the world, open the game menu and choose Open to LAN.
3. Review the game mode and command permission for joining players, then start the LAN world.
4. Ask the other Java players to check their Multiplayer list.

Success check: Your friend finds and joins the LAN world.

Troubleshooting: Check editions, versions and local-network access if the session does not appear.

Use matching game versions. Java LAN and Bedrock invitations are different workflows; this is not an internet server setup.
