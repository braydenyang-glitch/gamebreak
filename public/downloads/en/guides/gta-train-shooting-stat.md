## Improve the character you actually use

Grand Theft Auto V · Story Mode · character skills · PC / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Official manual · character-specific skill progression

Train the intended protagonist; progress is not shared between Michael, Franklin and Trevor.

Before you start: Access to a Shooting Range.

1. Switch to the protagonist you want to improve.
2. Check that character’s Shooting stat.
3. Visit an available Shooting Range.
4. Follow a shooting challenge and focus on accurate hits.
5. Compare the same character’s stat after practice.

Success check: You can track training on the intended character.

Troubleshooting: Another protagonist did not improve: Skills are separate for each character. Handling still feels poor: Review aiming settings as well as the skill stat.

Practice can improve accuracy, reload speed and ammunition capacity. No fixed training time is promised.
