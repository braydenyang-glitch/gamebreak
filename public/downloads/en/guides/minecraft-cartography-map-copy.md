## Copy or lock a map at a cartography table

Minecraft · Java / Bedrock · cartography table · PC / Mobile / Console

Source checked: 2026-10-20. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · cartography table

Empty map makes a copy; glass pane locks the map.

Before you start: An explored map, a cartography table, and an empty map or glass pane.

1. Open the cartography table.
2. Put the explored map in the first input.
3. Use an empty map in the second input for a copy.
4. Alternatively use a glass pane when you want a locked map.
5. Check the output preview and take the intended result.

Success check: You receive the selected copy or locked map.

Troubleshooting: Check the two troubleshooting cases below.

In Bedrock, a compass adds locator functionality; ordinary maps do not automatically show a player pointer.
