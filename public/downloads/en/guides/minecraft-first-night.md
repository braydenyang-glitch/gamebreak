## Prepare a safe first-night shelter

Minecraft · Java / Bedrock · PC / Mobile / Console

Source checked: 2026-10-15. Unverified · Not playtested; source review does not prove latest-patch accuracy.
Java / Bedrock · Overworld survival basics

Before dark, enclose a small shelter, light it with torches and use a bed if you have one.

Before you start: A Survival world, building blocks and ideally sticks and coal.

1. Collect building blocks while it is daylight.
2. Close off a small shelter with blocks so mobs cannot reach you.
3. Craft torches using sticks and coal, then light the shelter.
4. If available, place a bed in your protected Overworld shelter and sleep when permitted.

Success check: You have a lit enclosed shelter before night.

Troubleshooting: If mobs can enter, inspect openings before expanding the base.

This is an Overworld beginner routine. Lighting reduces ordinary dark-area spawns; it does not remove every danger or secure an open entrance.
