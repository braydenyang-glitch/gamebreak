# GameBreak — Minecraft

Minecraft is a block-building sandbox. In Survival, gathering, crafting and exploring support one another. Start with a small shelter and reliable food before planning deep mines or distant expeditions. These manuals cover ordinary vanilla play; always check whether your world is Java or Bedrock.

## Your first night: a small, safe start

Aim for a usable shelter and basic crafting, then expand in daylight.

Vanilla Survival • Java and Bedrock; edition differences noted. Sources reviewed, not playtested.

1. Collect logs, convert them to planks, and fill the four inventory crafting slots with planks to make a crafting table.
2. Place the table and use its recipe book to make sticks and a wooden pickaxe. Check missing ingredients before gathering more.
3. Before darkness, enclose a small space and close its entrance. Light the interior when you have torches; decoration can wait.
4. Keep food and spare blocks on your hotbar. At sunrise, look outside before leaving; daylight does not remove every threat.

A first-night shelter is temporary. Improve lighting and entrances before treating it as a permanent base.

## Shield, spacing and a planned retreat

Use defense to create room for a deliberate attack instead of trading every hit.

Vanilla Survival • Java and Bedrock; edition differences noted. Sources reviewed, not playtested.

1. Craft a shield with six planks and one iron ingot. Put it in the off-hand slot so your main hand can hold a weapon.
2. In Java, hold Use Item to raise the shield; in Bedrock, sneak while holding it. Practice the edition-specific action before fighting.
3. Face the incoming attack. A shield mainly protects the front, so step back when enemies approach from several directions.
4. Keep an open route to shelter and eat before re-engaging. Treat blocked attacks as a chance to reposition, not permission to stand surrounded.

Shields do not stop every damage type, and axes can disable them. Java and Bedrock combat timing also differs.

## From stone tools to your first iron

Match the tool to the ore, then turn raw iron into usable ingots.

Vanilla Survival • Java and Bedrock; edition differences noted. Sources reviewed, not playtested.

1. Use a wooden pickaxe to obtain cobblestone, then craft a stone pickaxe before mining iron ore. A wooden pickaxe cannot harvest iron.
2. Craft a furnace using eight cobblestone around the outside of the table grid. Leave the center empty.
3. Put raw iron in the furnace input and valid fuel, such as coal, in the fuel slot. Collect iron ingots from the output.
4. Spend the first ingots on the next task: an iron pickaxe for diamond ore, or a shield for exploration. Keep a spare tool at base.

Check the recipe book for your version. These are ordinary survival recipes, not modded ore processing or an optimized mining-level chart.

## Explore and find your way home

Record a destination before leaving and use coordinates as a return plan.

Vanilla Survival • Java and Bedrock; edition differences noted. Sources reviewed, not playtested.

1. Record your base X, Y and Z. Java exposes coordinates through F3; Bedrock has a Show Coordinates world setting.
2. X and Z describe horizontal position; Y is height. Record the cave entrance separately so returning above ground is easier.
3. An ordinary compass points toward world spawn in the Overworld. If your base is elsewhere, your recorded coordinates are the better reference.
4. Bring food, light and blocks. Pick a short first route, mark junctions consistently, and return before supplies become a problem.

Ordinary compasses do not navigate the Nether or End reliably. This guide is for Overworld travel.

## First commands in a practice world

Try small, understandable commands and keep your normal survival world separate.

Vanilla Survival • Java and Bedrock; edition differences noted. Sources reviewed, not playtested.

1. Create a practice world. Enable commands in Java or cheats in Bedrock; multiplayer also requires permission from the world or server owner.
2. Open chat and enter /help. Read the suggestions shown by your own game instead of pasting a command written for another edition.
3. In either edition, /give @s minecraft:torch 16 gives the executing player sixteen torches when permitted. Here @s means the command executor.
4. Use /time set day to make the practice world daytime. Stop after one change and check the result before trying another command.

Bedrock cheats disable achievements for that world even after cheats are turned off. Java item-data and Bedrock component syntax are not interchangeable.

## Start a shared base with friends

Agree on the edition and a small shared plan before everyone spreads out.

Vanilla Survival • Java and Bedrock; edition differences noted. Sources reviewed, not playtested.

1. Match the edition first: vanilla Java and Bedrock do not directly join one another. Confirm compatible versions and any server-required packs.
2. Java players can use Multiplayer and Add Server, or join a LAN world on the same network. Bedrock players can use friend invitations.
3. Suggested roles: one player gathers food, one collects building blocks, and one prepares light. Share the base coordinates before splitting up.
4. Label shared storage and keep spare tools inside. Agree which materials are communal before spending rare resources on personal projects.

Server rules and add-ons can change gameplay. A normal member does not automatically have operator permissions or access to every command.
