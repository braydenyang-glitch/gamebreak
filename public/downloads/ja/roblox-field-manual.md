# GameBreak — Roblox

このRoblox欄はLSPLASHのDOORS専用です。Hotelでは部屋の探索、エンティティの警告の理解、障害の解決で進みます。通常の生存法と協力の習慣をまとめていますが、更新・イベント・モディファイアで遭遇は変わり得ます。公式も仕様変更の可能性を案内しています。

## Hotelの主な障害を理解する

固定の部屋配置や暗号ではなく、流れを理解する。

Roblox DOORS・モディファイアなしの通常Hotel。コミュニティ資料確認済み。実機検証・イベント攻略ではない。

1. 受付の鍵で最初の施錠扉を開ける。その後も通常の鍵付き扉では近くの引き出しや台を調べる。
2. 図書館で記号と数字の対応を示す本を集め、紙の記号順からその回の5桁の暗号を作る。
3. 図書館ではFigureを避けて慎重に動く。しゃがみは音を抑えるが、接触や接近を安全にはしない。
4. 最後の電気室ではブレーカースイッチを探し、制御室へ。パネルに表示される組合せに従って電源を復旧し、出口へ進む。

図書館の暗号はその回で決まる。特殊モードや後の階層は別ルールで、Minesやイベントの攻略ではない。

## Rush・Hide・Seekで対処を変える

DOORSでは敵の識別が大切。すべてに同じ隠れ方は通用しない。

Roblox DOORS・モディファイアなしの通常Hotel。コミュニティ資料確認済み。実機検証・イベント攻略ではない。

1. 入室時に使える隠れ場所を探す。Rushの接近音や、照明がある場所の点滅に備えて隠れる準備をする。
2. Rush通過前に隠れ、攻撃が終わって経路が安全なら出る。長居するとHideに追い出される。
3. HotelのSeek追跡ではGuiding Lightの経路へ動き続ける。低い隙間はしゃがみ、引き出し探しで止まらない。
4. 追跡終盤の廊下では炎や伸びる腕を避ける。何度も振り返らず、前の通れる部分を見る。

隠れるまでの固定秒数は使わない。警告・部屋・設定で変わる。Ambushは戻ってくるため別の対応が必要。

## 照明・ロックピック・2種類の通貨

道具は必要な障害に使い、GoldとKnobsを区別する。

Roblox DOORS・モディファイアなしの通常Hotel。コミュニティ資料確認済み。実機検証・イベント攻略ではない。

1. 安全な時に引き出しや台で物資を探す。全部調べ切るより、接近する敵への対応時間を残す。
2. 見える場所では懐中電灯を消す。電池は対応する照明を充電するので、残量を見て必要な人に譲る。
3. ロックピックは対応する鍵に使うと消費される。鍵探しが難しい時に温存。図書館の暗証錠やスケルトンキー用の錠には使えない。
4. 探索中のGoldはJeffの店で使う。Knobsは出発前の購入などに使う別の通貨なので、会計前に種類を確認する。

品ぞろえ・価格・性能は変わり得る。固定価格や出現率、必ず売る商品は保証しない。

## 進路を見失わず部屋を探す

扉番号を覚え、隅々を調べる前に短い探索順を決める。

Roblox DOORS・モディファイアなしの通常Hotel。コミュニティ資料確認済み。実機検証・イベント攻略ではない。

1. 入る扉の番号を覚える。複数の番号付き出口がある時は、順番から次の番号を判断する。
2. 通常の施錠扉では引き出しや台を順に調べる。片側から探し、未確認の場所を把握する。
3. 必要物が見つからない時はGuiding Lightのヒントを見る。障害解決の助けであり、敵から守る盾ではない。
4. Dupeで番号が乱れたり忘れたりしたら、怪しい扉に触れる前に仲間の記憶を確認。手当たり次第に開けない。

モディファイアでヒントが弱まったり消えたりする。部屋は変わるので、スクリーンショットと同じ経路とは限らない。

## 追跡前に操作と設定を覚える

実際の操作表示を使う。DOORSはMinecraft型のコマンド・サンドボックスではない。

Roblox DOORS・モディファイアなしの通常Hotel。コミュニティ資料確認済み。実機検証・イベント攻略ではない。

1. PCはWASDで移動、Eで通常操作。物を拾い、解錠表示が長押しを求める時は押し続ける練習をする。
2. PC標準配置のCでしゃがみ、立ち上がりも練習。追跡中の低い障害で初めてボタンを探さない。
3. モバイルは表示された操作・しゃがみボタンを使い、所持品欄をタップして道具を選ぶ。家庭用機は表示されたボタン記号に従う。
4. 設定で視点感度や音量を扱いやすく調整。未知の区間へ行く前に道具の切替も練習する。

キーや画面は変わり得る。/skip-entityのような架空の生存コマンドは使わず、実際の表示を確認する。

## 同じ隠れ場所を奪わず協力する

短い報告と集合の習慣で、避けられる失敗を減らす。

Roblox DOORS・モディファイアなしの通常Hotel。コミュニティ資料確認済み。実機検証・イベント攻略ではない。

1. 分担案：1人が次の扉番号を伝え、他の人は左右に分かれて物資探索。何部屋も先に進まず、準備を確認する。
2. 危険前に別々の隠れ場所を確認。各自が空いている場所を知っていれば、警告がすぐ行動につながる。
3. 図書館では記号と数字、紙の順番を共有。1人が暗号を入力し、他の人はFigureから距離を取る。
4. 追跡や長い探索後に集合する。何部屋も遅れるとVoidで移動させられ、ダメージを受けるため、遅い仲間を確認する。

役割は協力の提案であり公式職業ではない。仲間による復活や隠れ場所の永久安全は保証しない。
