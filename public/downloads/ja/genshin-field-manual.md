# GameBreak — Genshin Impact

原神はオープンワールド探索と、戦闘中に交代できるパーティーを組み合わせた作品です。元素スキル・爆発・反応で仲間を連携させます。まず物語と移動地点を進め、使えるチームを育ててから収集や聖遺物を詰めましょう。

## まずひとつの元素反応を練習

長い手順を真似する前に、自分の攻撃の元素を確かめます。

一般的な元素戦闘。実測火力や現行順位は示しません。

1. 2人のスキルと爆発を読み、どの動作で元素が付くか確認します。
2. 対応する敵に水・炎・氷・雷を付け、風元素で拡散を確認します。
3. 元素アイコンと反応名を見て、どの操作で起きたか分かる速さで繰り返します。
4. 移動と防御を加えてから手順を伸ばし、回避用のスタミナを残します。

敵の無効化や固有能力で結果は変わります。初心者向け練習で、万能な最適手順ではありません。

## 各枠の役割を決める

使いやすいチームには明確な順序と生存手段が必要です。

序盤の編成手順。装備選びはキャラクターごとに確認します。

1. 所持キャラで主な攻撃方法を決め、中心となるスキルか爆発を書き出します。
2. 反応・強化・回復・バリアでその動作を支えます。固定編成ではなく考え方の例です。
3. 新しいチームを育て始める前に、武器レベル、必要な天賦、聖遺物のメイン効果を確認します。
4. 同じ戦闘で試し、生存・エネルギー・火力の弱点を一度にひとつだけ直します。

★5装備や人気編成でも、所持キャラと育成状態に合うとは限りません。

## 樹脂を具体的な育成に使う

不足素材から逆算し、目的のない周回を避けます。

素材計画。消費量と報酬倍率はゲーム内表示を確認します。

1. 次のキャラクター・武器育成画面で不足素材とモラを確認します。
2. 素材の入手先を開き、武器素材の秘境では表示された開催曜日を確認します。
3. 自然回復する天然樹脂を今の不足に使い、受取前に消費量を確認します。
4. 必要分がそろったら周回を止め、次の目標を決めます。脆弱樹脂は日々の使用と分けて管理します。

原石での回復を必須にしないでください。自然回復を使う計画です。

## 現在地を見失わず1地域を探索

移動地点・任務追跡・地図の階層を組み合わせます。

ネタバレを抑えた探索手順。完全収集ルートではありません。

1. 近くのワープポイントと神像を開き、遠い目標を並行せずひとつだけ追います。
2. 瞳が見つからない場合、公式テイワットマップの地域と地下階層を照合します。
3. 共鳴石の範囲は正確な一点ではありません。高所、地下、地形の裏も探します。
4. 取得を確認して印を付け、未解決の謎は後で戻れるよう記録します。帰りのスタミナも確認します。

任務や地域固有の仕組みが必要な収集物もあります。地図にあるだけで到達できるとは限りません。

## 通貨を使う前に祈願を読む

祈願の種類、ルール、自分の上限を分けて考えます。

ルール確認と予算管理。抽選結果や開催中祈願の推奨は行いません。

1. 使いたい祈願そのものを開き、詳細・対象・終了時刻を読みます。
2. 原石を交換する前に、紡がれた運命・出会いの縁など何を使うか確認します。
3. その祈願の履歴と保証ルールを確認し、キャラ・武器・特殊祈願を混同しません。
4. 使う通貨の上限を決め、利用できるお試しを遊び、上限で止めます。

レアリティ保証が希望の品の保証とは限りません。現行のゲーム内詳細を優先します。

## 冒険ランクが止まったら

アカウント進行とキャラクター・武器育成を分けて確認します。

一般的なランク確認。自分のアカウントに表示された条件を使います。

1. 経験値が止まったように見えたら、冒険ランクと突破任務を確認します。
2. 挑戦前に、使用チームの武器・重要天賦・聖遺物・生存手段を確認します。
3. 準備ができたら必要な突破任務をクリアします。蓄積した冒険経験はその後に反映されます。
4. フィールドが厳しい場合、利用可能な世界ランク調整を確認し、弱点をひとつ育成して再挑戦します。

アカウントランクは装備育成の代わりになりません。難度上昇で未育成部分が目立つ場合があります。
