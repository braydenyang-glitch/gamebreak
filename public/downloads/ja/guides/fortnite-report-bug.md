バトルロイヤル · メニュー未検証

ゲームメニュー → Report → Submit a report → A bug を開き、画像を確認して送信します。

始める前に: できれば不具合が画面に残っている状態。

1. ゲームメニューの三本線から Report、Submit a report を選びます。
2. A bug と近い理由を選び、該当しなければ Other を使います。
3. 画像を確認・撮り直しし、Continue、Accept で送信します。

成功の確認: 報告の確認画面まで進みます。

トラブル対処: 画像に映らなければ、安全に再現できる範囲で撮り直します。

Epic は問題が見える間の報告を勧めています。送信しても修正済みとは限りません。
