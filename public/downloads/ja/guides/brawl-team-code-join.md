チームロビー · 配信元サポート確認日 2026-10-25

キャラクター横の + から、主催者は Create、参加者は Join と共有コードを使います。

始める前に: チームプレイが可能なアカウントと有効なコード。

1. 主催者はキャラクター横の +、Create を選びます。
2. 表示されたコード、QR、リンクを参加してほしい人へ共有します。
3. 参加者は +、Join を選び、共有された方法を使います。
4. 主催者がイベントを選び、全員が I’m Ready で準備完了にします。

成功の確認: マッチング前に目的の人が同じロビーへ集まります。

トラブル対処: イベントを選べるのは主催者です。入れなければコードと空き枠を確認します。

通常チームのロビーとフレンドバトルは別です。招待やイベントに制限がある場合があります。
