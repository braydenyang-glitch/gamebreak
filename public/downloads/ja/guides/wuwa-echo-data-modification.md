Data Modification · Ver.2.3 の資料

Terminal → Data Bank → Data Modification を開きます。

始める前に: Modifier と未強化の星 5 音骸。

1. 使う共鳴者と目標能力を先に決めます。
2. Terminal → Data Bank → Data Modification を開きます。
3. 対応する未強化の星 5 音骸を選びます。
4. 第 1 メインステータスの候補を選びます。
5. 選択と費用を確認して確定します。
6. 変更後の音骸を確認します。自動でロックされます。

成功の確認: 選んだ第 1 メインステータスが反映されます。

トラブル対処: 選べなければレア度と強化済みかを確認します。この機能はサブ能力の変更ではありません。
