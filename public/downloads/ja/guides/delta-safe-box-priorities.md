Operations の Safe Box 内の品は死亡時に保護されます。バッグ全体を守るものではありません。

始める前に: 有効な Safe Box と現在の規則に対応する品。

1. 有効な Safe Box、容量、利用期限を確認します。
2. 残したい対応の貴重品や任務品を選びます。
3. 中へ移し、移動先を確認します。
4. 物資を集める間も中身を見直し、外の品のために脱出を計画します。

成功の確認: 選んだ品が Box 内に表示されます。

トラブル対処: 禁止品や大きすぎる品は入らない場合があります。季節の利用期限と画面の規則も確認します。

Garena の Operations 資料に基づきます。Global の規則、品の制限、シーズンの利用条件は異なる場合があります。
