Settings → Game → Preferred Item Slots で種類ごとの枠を設定します。

始める前に: Game 設定と対応するバトルロイヤル。

1. Settings の Game を開きます。
2. Preferred Item Slots の Configure を選びます。
3. よく使う武器の種類を好みの枠へ割り当てます。
4. 回復などの枠を残して適用します。
5. 対戦で空き枠を 1 つ確保し、対応品を拾います。
6. 位置を確認してから切り替え操作を練習します。

成功の確認: 拾った対応品が意図した枠へ入ります。

トラブル対処: 満杯なら空きを作ります。消耗品が右へ移動するなら Auto-Sort Consumables to Right も確認します。

特定の銃を保存する機能ではなく、種類による振り分けです。メニューは現行版で確認します。
