Java / Bedrock · 製図台

白紙の地図で複製し、板ガラスで固定します。

始める前に: 探索済み地図、製図台、白紙の地図か板ガラス。

1. 製図台を開きます。
2. 探索済み地図を最初の枠へ入れます。
3. 複製なら 2 枠目に白紙の地図を入れます。
4. 固定するなら代わりに板ガラスを入れます。
5. 完成プレビューを確認して取り出します。

成功の確認: 目的の複製地図か固定地図を得ます。

トラブル対処: 紙は拡張用です。固定した地図は更新しないので、新規探索は未固定のものを使います。

Bedrock ではコンパスで位置表示を追加します。普通の地図にプレイヤー印が必ずあるとは限りません。
