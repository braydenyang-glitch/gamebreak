鉄のツルハシを持ち、座標を見ながら深い地層を探します。古い Y=11 を万能ルールにしません。

始める前に: 鉄のツルハシ、食料、たいまつ、ブロック、帰路。

1. 出発前に拠点の座標を記録します。
2. Java は F3 の XYZ、Bedrock はワールドの Game 設定で Show Coordinates を使います。
3. 鉄のツルハシを持ちます。石のツルハシではダイヤモンド回収に進めません。
4. 階段など戻れる経路で降り、落下穴と溶岩に注意します。
5. 埋まった場所も探します。1.18 後は下ほど鉱石が多く、空気に露出した鉱石は少なくなる分布です。
6. 鉄のツルハシで採掘し、物資が尽きる前に戻ります。

成功の確認: 鉱石を見つけて適した道具で回収し、戻れます。

トラブル対処: 生成バージョンを確認し、洞窟の見える壁以外も探します。確実な鉱床を保証する経路はありません。

準備と分布の原則で、測定した最適 Y 座標や時間あたり採掘数ではありません。MOD や旧地形は異なる場合があります。
