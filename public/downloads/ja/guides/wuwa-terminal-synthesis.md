ターミナル合成 · Ver.2.0 の資料

Terminal → Synthesis で、Purification と Conversion を区別します。

始める前に: 合成機能とレシピの材料。

1. 強化画面で必要素材とレア度を確認します。
2. Terminal の Synthesis を開きます。
3. 異なるレア度をまとめるレシピは Purification を使います。
4. 同じ分類・レア度内の記載された交換は Conversion を使います。
5. 材料、数量、完成品を確認して確定します。
6. 強化画面で所持数を確認します。

成功の確認: 意図した育成素材が手に入ります。

トラブル対処: 自由な品の変換はできません。足りなければレア度と数量を再確認します。
