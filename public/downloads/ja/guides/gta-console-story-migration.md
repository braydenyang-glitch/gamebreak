PS4 / Xbox One → PS5 / Xbox Series X|S

旧版でアップロードし、新版でダウンロードします。

始める前に: 同じ Rockstar Games アカウントへ連携したコンソールアカウント。

1. 両コンソールのアカウントが目的の Rockstar アカウントと連携しているか確認します。
2. PS4／Xbox One で Pause → Game → Upload Save Game を開きます。
3. 対象セーブを選んでアップロードします。
4. PS5／Xbox Series X|S のストーリー画面か Game で Download Save Game を選びます。
5. 内容を確認してから移行を承認します。
6. 読み込んだ進行を確認します。以後のセーブは各版で別です。

成功の確認: 新コンソール版で選んだ進行を読み込めます。

トラブル対処: アップロード保存期間は 90 日です。資料のダウンロード手順では同じアカウントで再移行できません。

PC、PS3、Xbox 360 のセーブは対象外です。確認画面をよく読んでください。
