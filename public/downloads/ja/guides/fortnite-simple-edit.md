配信元の Simple Edit ヘルプ

Game 設定で Simple Edit を有効にし、変えたい部分を見ます。

始める前に: 対応する建築モードと編集できる建築。

1. Settings の Game を開きます。
2. Simple Edit をオンにします。
3. Tap to Simple Edit はオンなら短押し、オフなら長押しです。
4. 静かな場所へ壁を建てます。
5. 変更したい部分を狙い、Edit を使います。
6. 開口部を確認し、別の部分でプレビューを学びます。

成功の確認: 補助選択で意図した編集ができます。

トラブル対処: ゼロビルドでは練習できません。Epic の案内では競技モードは非対応です。
