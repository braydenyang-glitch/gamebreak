音骸プリセット · Ver.2.1 の資料

Echo Preset で Current Setup を保存し、他の構成を適用する前に比較します。

始める前に: 所持音骸と装備画面。

1. 共鳴者の音骸装備画面を開きます。
2. 右下の Echo Preset を選びます。
3. Current Setup から Save As Preset を選びます。
4. 用途の分かる名前を付けます。
5. 保存済みプリセットのステータス比較を開きます。
6. 現在の共鳴者へ使う場合だけ Apply を選びます。

成功の確認: 名前付きの構成が保存され、意図した装備になります。

トラブル対処: 適用前に現在構成と比較します。武器は保存対象とは別に確認します。

構成の保存であり、最適な装備と認定する機能ではありません。
