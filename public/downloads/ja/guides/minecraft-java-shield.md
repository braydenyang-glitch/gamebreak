Java の盾 · 初期マウス操作

盾を作り、攻撃の方向を向いて Use Item を押し続けます。

始める前に: 作業台、板材 6 個、鉄インゴット 1 個。

1. 作業台の 3 × 3 を開きます。
2. 板材 6 個を Y 字型に置き、上段中央に鉄インゴット 1 個を置きます。
3. 盾を取り出して持ちます。
4. 攻撃が来る方向を向きます。
5. Java の初期設定では右クリックの Use Item を長押しします。
6. 耐久値を確認し、必要なら金床と板材で修理します。

成功の確認: 盾を構え、前からの防御可能な攻撃を防ぎます。

トラブル対処: 方向を確認します。すべての攻撃を防げるわけではなく、斧は盾を無効化できます。構えられなければ持ち物とキーを確認します。

Java のマウス操作です。Bedrock の防御操作は異なります。修理費用と耐久値はゲーム内で確認します。
