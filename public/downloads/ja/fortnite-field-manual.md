# GameBreak — Fortnite

バトルロイヤルは物資回収、戦闘、安全な場所への移動を組み合わせるモード。建築ありかゼロビルドかを選び、現在の島で持ち物と着地の基本手順を覚えましょう。

## 適切な距離と位置から戦う

武器の役割を決めて遮蔽物への退路を残します。建築は対応モードで練習しましょう。

バトルロイヤル／ゼロビルド。現在のモードと島が対象。Reloadや世界を救えとは別です。

1. 実際に拾った武器から、近距離用と離れた相手用を選ぶ。
2. 撃つ前に遮蔽物を探し、接近時に別方向へ体をさらさないか確認する。
3. 慣れたスロットで武器を切り替え、安全な時間に装填と回復を行う。
4. 建築ありなら防御用建築を一つ練習。ゼロビルドでは次の遮蔽物を探す。
5. 負けた後は、位置取り・距離・感度のどれか一つだけ調整する。

練習手順であり、シーズン武器ランキングではありません。武器はモードや更新で変わります。

## 救助の場面でも分隊を保つ

全員で危険な場所へ飛び込まず、安全な救助計画を共有します。

バトルロイヤル／ゼロビルド。現在のモードと島が対象。Reloadや世界を救えとは別です。

1. 同じ着地区域を決め、変更する時は離れる前に伝える。
2. 仲間がダウンしたら、蘇生の前に遮蔽物と敵の攻撃を確認する。
3. 仲間が撃破されたら、通常の蘇生ではなく現在のリブートカードとバンの案内を確認する。
4. 一人が救助を担当し、他の人は接近経路を警戒。ストームで無理になった経路は変更する。
5. 救助後は使える装備を分け、合流してから次の戦闘へ進む。

リンク先のv8.30はリブート導入時の資料です。当時の時間や装備数値を現在の値として使わないでください。

## 持ち物の各枠に役割を持たせる

次の戦闘に向け、使える武器・回復・現在手に入る補助アイテムを整理します。

バトルロイヤル／ゼロビルド。現在のモードと島が対象。Reloadや世界を救えとは別です。

1. 近距離用と遠距離用を決まった枠に置き、戦闘中に探さず切り替えられるようにする。
2. 別の銃を拾う前に、弾薬と現在の構成にない役割を補えるか確認する。
3. 可能なら回復アイテムを残し、使用条件を読む。何でも同じものを回復するとは限りません。
4. 建築ありでは開けた場所を渡る前に資材を確認。ゼロビルドでは遮蔽物と補助アイテムを優先する。

Epicの開発者資料はBRに似た構造の説明です。現在の戦利品や全モードの枠数を保証しません。

## ストームに追われる前に移動する

古いシーズンの経路を暗記するより、現在の試合マップで本命と予備の移動先を決めます。

バトルロイヤル／ゼロビルド。現在のモードと島が対象。Reloadや世界を救えとは別です。

1. 着地点と近くの代替地を決め、混雑していれば早めに変更する。
2. 最初の物資回収後、マップで安全地帯とストームの残り時間を確認する。
3. 遮蔽物と別の出口がある地形を通り、遠くの銃声をすべて追わない。
4. 円が変わるたびに地図を確認し、追加の物資より先に次の目的地を共有する。

地点や移動アイテム、乗り物は変わります。固定出現や安全な着地を保証する手順ではありません。

## 操作と重要な音の表示を調整する

自分の機器で分かりやすく押しやすい操作にします。他人の感度は試す出発点にすぎません。

バトルロイヤル／ゼロビルド。現在のモードと島が対象。Reloadや世界を救えとは別です。

1. メニューからSettingsを開き、入力機器に合うキーボード矢印またはゲームパッドのタブへ進む。
2. 武器切替・インタラクト・移動の割り当てを確認し、無理なく届くキーにする。
3. AudioでVisualize Sound Effectsを試して適用。特定の音が画面上の手がかりになります。
4. 短く練習し、感度か表示を一つだけ調整してから違いを比べる。

設定手順でありチートコマンドではありません。音の表示で敵を完全追跡できるわけではなく、設定タブも機種で異なります。

## 短いプレイでもクエストを進める

達成しやすいクエストを選び、条件と結果を確認。XPと報酬の受取条件は別です。

バトルロイヤル／ゼロビルド。現在のモードと島が対象。Reloadや世界を救えとは別です。

1. 現在のクエスト一覧から、遊ぶバトルロイヤルのモードに合う目標を一つ選ぶ。
2. 着地計画の前に、必要な行動・場所・アイテム・期限を読む。
3. 仲間の安全やストーム移動を無視せず、通常のプレイの中で目標を進める。
4. 試合後に進捗を確認し、報酬を受け取る前にパスのレベル・前提条件・所有条件を確認する。

XP量やクエスト、報酬は変わります。即レベルアップ、固定XP、プレミアム報酬の無料入手を保証しません。
