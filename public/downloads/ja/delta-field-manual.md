# GameBreak — Delta Force

Operationsは脱出型モード。経路、装備予算、撤退判断が重要です。高価な戦利品を狙う前に、無理のない装備で小さな目標を達成し、一つのマップを覚えましょう。

## 銃・弾薬・交戦距離を合わせる

値段やレア度だけで選ばず、使い慣れる基本構成を作ります。

PC・Operations。地域版の説明を確認。Warfareのルールとは別です。

1. 銃と弾薬の詳細で、口径の適合と表示される貫通情報を確認。
2. ガンスミスで一度に一つの部品を比較し、買い直せる構成にする。
3. 交戦前に遮蔽物と退路を探し、不慣れな銃を開けた場所で試さない。
4. 帰還後、弾薬・反動制御・位置取りのどれが問題だったか記録し、次回は一つだけ変える。

OperationsとWarfareでは調整が異なる場合があります。確殺条件や最強構成の保証ではありません。

## 各自行動ではなく分隊で動く

オペレーターの説明とマーカーを使い、索敵・支援・撤退の役割を決めます。

PC・Operations。地域版の説明を確認。Warfareのルールとは別です。

1. 選んだオペレーターのOperations向け能力説明を読む。Warfareの説明を流用しない。
2. 次の経路を調べる人と、物資回収中に後方を警戒する人を決める。
3. 試合外でOperationsのマーカーホイールを設定し、敵・物資・移動を短く伝える。
4. Morseなどの索敵役は実際に検知した情報を伝え、不明点があれば退路を残す。
5. 短時間分かれる前に集合場所を決め、弾薬や医療品が不足したら一緒に撤退する。

能力の範囲や再使用時間は変更されます。永続的な索敵だと思い込まないでください。

## 出撃予算を守り、戦利品を整理する

保管品、持ち込み装備、任務素材を分け、失敗しても次の出撃ができるようにします。

PC・Operations。地域版の説明を確認。Warfareのルールとは別です。

1. 予備装備はStashに残し、今回の目的に必要な物だけLoadoutへ入れる。
2. 高価な物をSafe Boxに入れる前に、収納条件と空きを確認する。
3. Gear Ticketがあれば、内容と制限を確認してから追加のTekniq Alloyを使う。
4. 脱出後は必要素材を残し、必需品を補充して、余剰と判断した物だけ売る。

脱出失敗で持ち物を失う場合があります。Safe Boxにも品目や利用権の制限があります。

## 回収ルートの前にマップを読む

公式マップで予習し、実際の出撃中に脱出条件を確認します。

PC・Operations。地域版の説明を確認。Warfareのルールとは別です。

1. 公式ツールでOperationsのマップと難易度を選び、まず一つを覚える。
2. 目標と近くのマーカーを確認し、全域を横断せず短い経路を考える。
3. 出撃中は脱出先、条件、残り時間を確認し、可能なら第二候補も決める。
4. 負傷、銃声、満杯のバッグをきっかけに経路を再評価。小目標の達成でも帰還を考える。

マップの提供状況や脱出ルールは変わります。古い経路情報だけで出口が使えるとは限りません。

## PCの音・ガジェット操作・マーカー設定

これはクライアント設定です。コンソールコマンドではありません。一つずつ変更して動作を確認します。

PC・Operations。地域版の説明を確認。Warfareのルールとは別です。

1. ヘッドホンでSettings → Audio → HRTFを開き、方向の聞き分けを比較する。
2. Control & Combatで、対応ガジェットのQuick Throw、Hold、Defaultを確認する。
3. 強い白色の閃光がつらければFlash Protectionを試す。効果を無効化する設定ではありません。
4. 戦闘前にマーカーホイールを設定し、敵と移動先のピンを練習する。

公式PC更新に記載された設定です。地域版や入力機器によって名称・利用可否が異なる場合があります。

## 部門任務とBlack Site強化をつなげる

レシピがあるから作るのではなく、実際に不足している物資から強化計画を立てます。

PC・Operations。地域版の説明を確認。Warfareのルールとは別です。

1. 部門任務を一つ選び、出撃前に達成条件を読む。
2. 次のSupply StationやBlack Siteの条件を確認し、不足素材を短くまとめる。
3. Black SiteのWorkbench、Pharmacy、Armor Benchのレシピを実際の消耗品と比べる。
4. ゲーム内で必要費用と製作時間を確認し、完成品を受け取って素材メモを更新する。

シーズン任務、利用権、レシピは変更されます。利益を保証する手順ではありません。
