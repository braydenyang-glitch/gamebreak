# GameBreak — Honkai: Star Rail

崩壊：スターレイルは星穹列車で宇宙を巡るターン制RPGです。敵の弱点、共有するSP、各キャラクターの役割を見て編成します。開拓クエストで行き先を増やし、レベル・光円錐・軌跡・遺物でチームを育てます。

## SPと弱点で戦闘を組み立てる

手動戦闘を練習するための基本手順。

通常のターン制戦闘向け。個別スキルの例外あり。

1. 狙う敵の弱点アイコンを確認。対応する属性で靭性を削れます。特殊なバリアやステージ条件は別に確認します。
2. 行動順と共有SPを確認し、次に誰がスキルを使うか決めてから行動します。
3. 通常攻撃はSPを回復し、スキルは消費することが多いですが、強化攻撃などの例外は説明で確認します。
4. 必殺技は火力・回復・防御のどれに使うか考えます。一戦を手動で試し、敗因が耐久・狙い・SP不足のどれか記録します。

特殊なキャラクターやモードではルールが変わるため、スキル説明と戦闘チュートリアルを優先してください。

## 最後まで戦えるチームを組む

役割、正しい形態、装備の相性から考えます。

キャラクター形態・光円錐の命途・基本編成。

1. 主なダメージ源と戦い方を決めます。耐久が足りなければ回復・防御役を入れ、その戦い方に合う支援を加えます。
2. 光円錐の追加効果を使うには、装備者の命途条件を確認します。レア度だけで選ばないようにします。
3. 編成画面で形態を確認。三月なのかや開拓者は形態で性能が異なるため、別の命途の攻略を流用せずプリセットに保存します。
4. 慣れた敵でSPの使い方を確認。全員が毎ターンスキルを必要とするなら、装備を強化する前に行動計画を直します。

これは編成の考え方で、最新ランキングではありません。敵によって必要な耐久・攻撃手段は変わります。

## 次の育成に必要な素材を集める

育成画面から短い周回計画を作ります。

素材計画向け。ドロップ数や現在の開拓力上限は断定しません。

1. キャラクター・光円錐・軌跡の育成画面で不足素材を確認し、すぐ役立つ育成に絞ります。
2. 素材の入手先か星間ピースガイドの生存手引で、疑似花萼・凝結虚影・侵蝕トンネル・歴戦余韻の報酬と条件を確認します。
3. 報酬受取前に開拓力の消費を確認し、目標分が集まれば止めます。追加回復は必要が明確になってから使います。
4. 育成ガイドの素材数が合わなければ軌跡の絞り込みを確認。「推奨する軌跡のみ」では予定した育成が除外される場合があります。

解放条件や先行体験は進行状況と現行ルールによります。古い画像よりロック表示を確認してください。

## 道順とクエストの行き詰まりを確認する

不具合と思う前に案内とクエスト状態を確認します。

クエスト案内と会話の競合。物語のネタバレは避けています。

1. クエストをひとつ追跡し、目的と場所を読みます。近くに見える印へ届かなければマップの階層を確認します。
2. NPCと話せない場合は競合表示を確認。別の進行中クエストが使用しているなら、指定されたクエストを進めて戻ります。
3. 地域やコンテンツがロックされていれば、ガイドかクエスト画面の解放条件から次の目標を決めます。
4. パムから開拓レベル報酬を受け取れなければ、列車のクエストが会話を使用していないか確認し、解決後に戻ります。

クエストによって地域やNPCの状態は変わります。再起動だけでは必要な進行を代わりに完了できません。

## 星玉を使う前に跳躍を確認する

跳躍の種類と履歴を確認し、上限を決めます。

跳躍の確認と予算管理。開催中ガチャの推奨ではありません。

1. 選んだ跳躍の詳細で、ピックアップ・終了時刻・必要通貨・確定ルールを確認します。
2. キャラクターイベント・光円錐イベント・恒常跳躍の回数を混ぜず、アカウント全体の回数でひとつの天井を予想しないようにします。
3. 跳躍→詳細→履歴を確認。直近の結果は反映が遅れることがあり、古い履歴が表示されなくても、それだけで確定回数がリセットされるわけではありません。
4. 回す前に止める回数とチケットの種類を確認し、終了間近という理由だけで使わず本命のために残します。

特定の結果や課金は勧めません。各跳躍のルールは現在のゲーム内詳細を優先してください。

## 次の均衡段階へ備える

物語とアカウントの進行を整理するチェック。

物語の進行と準備向け。現在の解放案内を優先します。

1. 次のクエスト条件と均衡の試練を確認し、全コンテンツが同じレベル条件だと思わないようにします。
2. 難しい試練の前に、主力のレベル・光円錐・よく使う軌跡を確認。攻撃役だけでなく耐久の弱点も補います。
3. 凝結虚影などの入口で実際の条件を確認。物語の条件や先行体験があるため、現在の案内に従います。
4. 進行後はガイドの新項目と開拓レベル報酬を確認。未完成の育成を増やしすぎず、次の強化をひとつ決めます。

アカウントレベルだけで戦力は決まりません。特定の高難度モードのクリアを保証するものではありません。
