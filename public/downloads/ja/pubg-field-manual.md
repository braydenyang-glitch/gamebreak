# GameBreak — PUBG: BATTLEGROUNDS

PC版PUBGでは射撃、物資回収、移動のタイミングを組み合わせます。武器を一つ覚え、無理のない着地区域とブルーゾーンへの対応を決めましょう。

## すべて変える前に、一つの武器を覚える

同じトレーニングを繰り返し、反動、部品、交戦距離の問題を分けて考えます。

PUBG: BATTLEGROUNDS・PC。ノーマル／ランクと現在の設定を確認。PUBG Mobile向けではありません。

1. トレーニングでよく拾う武器を選び、最初は同じ照準器を使う。
2. 同じ標的で短い連射と長い連射を比べ、実際の弾の広がりを見る。
3. 適合する反動・安定性の部品を一つ加え、他の条件を変えずに再試行する。
4. 実戦では撃つ前に遮蔽物を選び、練習した距離で戦う。装備に合わない戦闘からは離れる。

練習標的は実戦のすべてを再現しません。固定のダメージや反動値を示すものではありません。

## ピン・物資連絡・安全な救助を組み合わせる

役立つ連絡は、敵の存在だけでなく、移動先や不足品も伝えます。

PUBG: BATTLEGROUNDS・PC。ノーマル／ランクと現在の設定を確認。PUBG Mobile向けではありません。

1. 近くの建物へ分かれる前に、着地区域と合流地点を決める。
2. 画面ピンに方向と遮蔽物の説明を添え、敵が動いたら更新する。
3. インベントリのラジオメッセージで、必要な弾薬・照準器・物資を知らせる。
4. ダウンした仲間は遮蔽物までの経路を確認してから運ぶ。運搬自体は蘇生ではありません。
5. 一人が接近経路を警戒し、別の人が救助。終わったら合流し、物資を分け直す。

現在のLimited Interactとラジオメッセージのキーを確認。導入時の資料を全員共通の配置として扱わないでください。

## 適合と回復を考えて物資を集める

使う武器を支え、回復品も入るバッグを目指します。武器を替えるたびに中身を見直しましょう。

PUBG: BATTLEGROUNDS・PC。ノーマル／ランクと現在の設定を確認。PUBG Mobile向けではありません。

1. 携帯武器の弾薬を確認し、どちらにも使えない弾は集めない。
2. 照準器、マガジン、グリップが装着済みか確認。適合品も装着してこそ役立ちます。
3. Settings → Gameplayで自動装着を確認し、武器交換後にもう一度持ち物を見る。
4. 医療品とブースト品を考えて組み合わせ、古い表ではなく現在の重量や使用説明を読む。
5. 長距離移動の前に不要な部品を整理し、使える予備を仲間へ渡す。危険な回収を長引かせない。

更新42.1で医療品の重量や使いやすさが変更。古い固定時間や数量はここでは使いません。

## 次の建物より次の円を考える

地形、白い円、現在のタイマーから経路を選びます。遅い横断一回に試合を賭けないようにしましょう。

PUBG: BATTLEGROUNDS・PC。ノーマル／ランクと現在の設定を確認。PUBG Mobile向けではありません。

1. 着地後、自分の位置と次の白い円を確認してから追加の回収地点を選ぶ。
2. 地形の遮蔽物と予備の方向を確保し、道路、尾根、狭い通路を確認する。
3. 遠い経路なら早めに移動手段を検討し、ブルーゾーンが来てから探さない。
4. 円が変わるたびに時間を確認して合流。移動が優先になったら物資回収を切り上げる。

公式42.1でブルーゾーンの時間とダメージ計算が変更。現在のタイマーを優先し、古い距離依存の助言に頼らないでください。

## Aim/Sound LabとPC操作を確認する

照準、音の方向、アイテム操作を短く練習します。コンソールコマンドではなく訓練と設定の手順です。

PUBG: BATTLEGROUNDS・PC。ノーマル／ランクと現在の設定を確認。PUBG Mobile向けではありません。

1. トレーニングに入り、現在のマップと操作案内でAim/Sound Labを探す。
2. 武器を一つ選んで照準練習を行い、感度を変える前に結果を記録する。
3. 普段のヘッドホンで音の練習をし、聞こえた方向と表示される答えを比べる。
4. Limited Interact、ラジオメッセージ、自動装着の設定を確認し、実戦の前に練習する。

Labは16.2の資料に記載。現在の入口案内を優先し、比較できるよう設定は一つずつ変えてください。

## 武器マスタリーを練習に活かす

マスタリーや武器統計をプレイの振り返りに使い、位置取りと生存の練習も続けます。

PUBG: BATTLEGROUNDS・PC。ノーマル／ランクと現在の設定を確認。PUBG Mobile向けではありません。

1. 武器マスタリーで実際によく使う武器を選び、すべてを同時に進めようとしない。
2. モードと武器のフィルターを確認し、似たモードの統計同士を比べる。
3. 安定した命中や射撃後の安全な移動など、目標を一つ決めて数回練習する。
4. 後から傾向と現在の報酬画面を確認し、古い報酬説明が今も当てはまると決めつけない。

18.2はマスタリー改修時の歴史資料です。現在の上限、XP、報酬条件はゲーム内で確認してください。
