# GameBreak — Minecraft

Minecraftはブロックで世界を作るサンドボックス。サバイバルでは採集・クラフト・探索がつながります。まず小さな拠点と食料を確保し、深い採掘や遠征はその後に。通常のバニラ向けなので、JavaかBedrockかを確認しましょう。

## 最初の夜：小さく安全に始める

使える避難所と基本のクラフトを整え、拡張は昼間に。

バニラのサバイバル・Java／Bedrock。版の違いは明記。資料確認済み、実機未検証。

1. 原木を板材にし、インベントリの2×2クラフト欄を板材で埋めて作業台を作る。
2. 作業台を置き、レシピ本で棒と木のツルハシを作る。不足材料を確認してから集めに行く。
3. 暗くなる前に小さな空間を囲み、入口を閉じる。松明があれば室内を照らし、装飾は後回し。
4. 食料と予備ブロックをホットバーへ。朝も外を確認してから出る。日光ですべての危険が消えるわけではない。

初日の避難所は仮拠点。照明や入口を整えてから本拠点にする。

## 盾・間合い・退路

攻撃を受け合うより、防御で反撃の余裕を作る。

バニラのサバイバル・Java／Bedrock。版の違いは明記。資料確認済み、実機未検証。

1. 板材6個と鉄インゴット1個で盾を作る。オフハンドに入れ、利き手には武器を持つ。
2. Javaでは「アイテム使用」を押し続け、Bedrockでは盾を持ってスニークする。戦闘前に版ごとの操作を練習。
3. 攻撃の方向を向く。盾は主に正面を守るので、複数方向から囲まれたら後退する。
4. 拠点への退路を残し、食事してから再戦する。防御成功は位置を変える機会であり、囲まれてよい理由ではない。

盾ですべてのダメージを防げず、斧で無効化されることもある。JavaとBedrockでは戦闘の間隔も異なる。

## 石の道具から最初の鉄へ

鉱石に合う道具を使い、鉄の原石をインゴットにする。

バニラのサバイバル・Java／Bedrock。版の違いは明記。資料確認済み、実機未検証。

1. 木のツルハシで丸石を集め、石のツルハシを作ってから鉄鉱石へ。木のツルハシでは鉄を回収できない。
2. 作業台の外周8マスに丸石を置き、中央を空けてかまどを作る。
3. 鉄の原石を上の欄、石炭などの燃料を燃料欄へ。完成した鉄インゴットを取り出す。
4. 次の目標に合わせて鉄を使う。ダイヤ採掘なら鉄のツルハシ、探索なら盾。拠点には予備の道具を残す。

自分の版のレシピ本を確認。通常サバイバルの手順であり、MOD加工や最適高度表ではない。

## 探索して、拠点へ帰る

出発前に目的地を記録し、座標を帰路の目印に。

バニラのサバイバル・Java／Bedrock。版の違いは明記。資料確認済み、実機未検証。

1. 拠点のX・Y・Zを記録。JavaはF3、Bedrockはワールド設定の「座標を表示」で確認する。
2. XとZは水平位置、Yは高さ。地上に戻れるよう洞窟入口も別に記録する。
3. 通常のコンパスはオーバーワールドのスポーン地点を指す。拠点が別なら記録した座標を頼りにする。
4. 食料・照明・ブロックを携帯。最初は短い経路にし、分岐を同じ方法で印付けし、物資が尽きる前に戻る。

通常のコンパスはネザーやエンドの案内には使えない。本稿はオーバーワールド向け。

## 練習ワールドでコマンド入門

小さく理解できるコマンドから試し、普段のワールドと分ける。

バニラのサバイバル・Java／Bedrock。版の違いは明記。資料確認済み、実機未検証。

1. 練習ワールドを作る。Javaはコマンド、Bedrockはチートを有効化。マルチプレイでは管理者の権限も必要。
2. チャットで /help を入力。別のエディションの命令を貼る前に、自分のゲームの候補を読む。
3. 権限があれば両版で /give @s minecraft:torch 16 を使い、実行者に松明16本を渡せる。@s は実行者。
4. /time set day で練習ワールドを昼にする。1つ変更したら結果を確認してから次を試す。

Bedrockはチートを後で無効にしても、そのワールドの実績が無効になる。Javaのアイテムデータ構文とBedrockの構文は別物。

## 友達と共同拠点を始める

エディションと小さな共同目標を決めてから出発する。

バニラのサバイバル・Java／Bedrock。版の違いは明記。資料確認済み、実機未検証。

1. まず版を合わせる。通常のJavaとBedrockは直接接続できない。互換バージョンと必要なパックも確認。
2. Javaは「マルチプレイ／サーバーを追加」、または同じネットワークのLANへ。Bedrockはフレンド招待を利用。
3. 分担案：食料、建材、照明をそれぞれ担当。別行動の前に拠点座標を共有する。
4. 共有チェストに表示を付け、予備道具を保管。希少素材を個人建築に使う前に共有ルールを決める。

サーバールールやアドオンで仕様は変わる。一般メンバーに管理者権限や全コマンドがあるとは限らない。
