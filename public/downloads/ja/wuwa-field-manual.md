# GameBreak — Wuthering Waves

鳴潮はソラリスを舞台とするオープンワールドアクションRPGです。漂泊者として共鳴者と旅をし、スキル・タイミング・交代を組み合わせて戦います。探索で素材と音骸を集め、役立つ育成へつなげましょう。

## 共鳴者の戦闘リズムを覚える

長いコンボの前に短い手順を練習します。

手動戦闘の練習向け。使用中の共鳴者の説明を優先。

1. ガイドのPath of Growthからスキルトレーニングへ進み、共鳴スキル・共鳴解放・共鳴回路を読みます。
2. 通常攻撃の流れと防御を練習します。敵の動きや回避・パリィの合図を見て、全ボタンを連打しないようにします。
3. 共鳴回路のゲージが増減する条件を確認。公式ガイドでその共鳴者の手順を読み、全員に同じ順番を当てはめません。
4. 変奏・終奏を使う交代前に協奏の準備を確認。狙った交代を入れた短い練習を行い、一度にひとつだけ手順を変えます。

敵の攻撃やキャラクターには例外があります。これは練習方法で、実測した最大火力コンボではありません。

## 仲間・武器・音骸をつなげる

キャラクター別ガイドと比較しやすい手順を使います。

編成計画と音骸プリセット。最新環境の順位付けではありません。

1. 中心にしたい共鳴者と戦い方を決め、合う仲間を選びます。倒れやすければ回復や防御を補います。
2. 端末のGuide Depotか公式ガイドで対象の共鳴者を選び、武器・音骸・育成順・仲間の提案を確認します。
3. 交代前に終奏の効果と対象を読み、武器や音骸の効果も担当する役割に合っているか確認します。
4. 変更前に音骸プリセットへ保存。表示ステータスを比較し、同じ敵で試して条件をそろえます。

ガイドは作者や更新時期で異なります。推奨装備が自分のアカウントで必ず最適とは限りません。

## 必要な素材のルートを作る

育成画面・採集地点・報酬コストをつなぎます。

資源計画向け。ドロップ数や開催中ボーナスは保証しません。

1. 育成ひとつに足りない素材と通貨を確認し、フィールド採集と挑戦報酬を分けて考えます。
2. 対応素材をバッグか共鳴者画面から開き、Collection Spotsで近くの採集地点を追跡します。
3. 報酬受取前にWaveplateの消費と報酬内容を確認し、不足している育成に使います。どの挑戦でも同じ素材が出るとは限りません。
4. 予定した周回後に所持数を確認し、次の育成分がそろえば止めます。星声の予算は日常の素材集めと分けます。

過去の報酬倍増イベントは常設ではありません。現在の受取画面と開催中の告知で費用・ボーナスを確認してください。

## 地域探索で道順を見失わない

移動地点・マップ階層・解放情報を使います。

基本の地域探索。全収集地点を網羅した地図ではありません。

1. 目的地が開くまでメイン任務を進め、近くの共鳴信標を開いて再訪しやすくします。
2. 利用可能ならマップのRegion Guideで機能の解放条件を確認し、入れない理由を調べます。
3. マップの階層と目標の高さ・入口を確認。平面上で近くても別の場所や階層にあることがあります。
4. 地域を移る前に任務・近くの採集・帰還地点を短いルートでまとめます。入れない場所は記録し、条件達成後に戻ります。

場所の解放は物語の進行で異なります。マップ機能で任務条件を無視することはできません。

## 通貨を使う前に集音を確認する

現行ルールを読み、可能なら先にキャラクターを試します。

集音の読み方。リンク先のイベント例は過去の告知で、現在の日程ではありません。

1. 開催中の集音と詳細を開き、対象・終了時刻・チケット種類・確認画面の交換費用を読みます。
2. その集音の確定・引継ぎルールを確認。キャラクター・武器・初心者・記念集音を同じルールだと考えないようにします。
3. 開催中にFirst Resonanceなどのお試しがあれば、攻撃と操作感を確認。遊び方が好きか考えてから回すか決めます。
4. 止める予算と使用量を決め、本命のために残します。過去の告知があるだけでは、その集音が今も開催中とは言えません。

結果や課金は勧めません。選んだ集音は現在のゲーム内詳細を基準にしてください。

## 探索を着実な育成につなげる

物語を進めながら使える主力を育てます。

初心者の育成方針。現在の上限や最適な高難度構成は断定しません。

1. 次のメイン任務の前提条件を読み、ガイドで今できる課題を選びます。新地域の追加だけで全員がすぐ入れるとは限りません。
2. 少数の主力共鳴者と武器を優先し、不足素材をゲーム内で確認。新しい全員に素材を分散しすぎないようにします。
3. 収集時はデータドックと音骸画面を確認。収集の進み具合、個別音骸の強化、装備効果を区別します。
4. 戦闘が難しくなったらスキルトレーニングと対象のガイドを確認。練習・武器・スキル・音骸のどこを改善するか決めます。

推奨や解放条件は変わることがあります。古い手順や上限値を前提にせず、現在の画面を確認してください。
