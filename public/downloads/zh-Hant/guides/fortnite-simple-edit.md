## 在自己建築上試用 Simple Edit

發行商簡易編輯支援

在 Game 設定開啟 Simple Edit，瞄準想修改的位置。

開始之前: 支援建造的模式，以及可編輯的建築。

1. 開啟 Settings，選 Game 分頁。
2. 開啟 Simple Edit。
3. 查看 Tap to Simple Edit：開啟使用點按，關閉使用長按。
4. 在安靜位置放一面牆。
5. 瞄準想改的區塊，使用 Edit 操作。
6. 檢查開口，再試其他區塊熟悉預覽。

成功判斷: 透過輔助選取完成預定修改。

疑難排解: 不能建造？Zero Build 不適合練此功能。 對局沒有選項？Epic 不在競技模式提供此功能。
