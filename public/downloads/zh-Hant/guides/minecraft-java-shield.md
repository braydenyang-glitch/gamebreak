## 製作並使用 Java 盾牌

Java 盾牌操作・預設滑鼠輸入

製作盾牌、面向攻擊，按住 Use Item 格擋。

開始之前: 工作台、六塊木材與一個鐵錠。

1. 開啟工作台的 3 × 3 格。
2. 放六塊木材形成 Y 字，頂排中央空格放一個鐵錠。
3. 取出並拿著盾牌，先做簡單測試。
4. 面向攻擊來的方向。
5. 按住 Use Item 舉盾，Java 通常是滑鼠右鍵。
6. 事後檢查耐久；適合時在鐵砧用木材修復。

成功判斷: 盾牌舉起，擋住正面可格擋的攻擊。

疑難排解: 仍受到傷害：檢查面向；不是每種攻擊都可擋，斧頭也能停用盾牌。 盾牌沒有舉起：確認拿著盾牌，並檢查 Java 的 Use Item 按鍵。

這是 Java 滑鼠操作；Bedrock 格擋方式不同。修復費用與剩餘耐久請在遊戲內確認。
