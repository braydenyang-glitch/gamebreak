發行商網路支援

暫停大量網路傳輸，在相近條件下比較同一模式。

開始之前: 線上對局，以及裝置網路與 Game 設定權限。

1. 暫停同一連線上的大型下載、上傳與串流。
2. 裝置支援時改用有線連線。
3. 開啟 Settings → Game → Language and Region。
4. 所屬地區有提供時，檢查 Subregion Preference。
5. 再次遊玩相同模式，比較反應速度。
6. 有改善再保留設定，並考慮可能增加的配對等待時間。

成功判斷: 能判斷連線變更是否改善延遲。

疑難排解: 仍有延遲？網路路由或伺服器壅塞可能不在你控制範圍。 更改偏好後排隊更久？重新考慮該偏好，它可能影響配對。

此方法針對網路延遲，不保證改善低幀率。
