將書本符號對應成數字，再依 Solution Paper 排順序。

開始之前: 圖書館遭遇，以及收集到的解謎線索。

1. 小心進入，穿越 Figure 路線前先觀察巡邏。
2. 從書架收集標記書本，記下符號與數字。
3. 到辦公室桌上取得 Solution Paper。
4. 依羅馬數字順序讀取五個符號位置。
5. 把每個符號換成對應書本記錄的數字。
6. 在樓上出口輸入五位數密碼，立即離開。

成功判斷: 用目前場次的密碼開啟圖書館出口。

疑難排解: 少一個數字？找出對應符號的書。 密碼不對？重新核對紙上的順序，其他場次的密碼沒有用。
