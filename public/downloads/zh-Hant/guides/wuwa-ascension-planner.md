共鳴者養成規劃記載於版本 2.7

開啟 Terminal → Resonators → 培養規劃器，查看各模組。

開始之前: 可使用角色培養規劃器，且有想提升的角色。

1. 開啟 Terminal → Resonators，進入培養規劃器。
2. 選想培養的共鳴者。
3. 查看共鳴者、武器、聲骸與技能模組。
4. 選一項可達成的下步升級，不必一次刷全部。
5. 用材料來源捷徑找到缺少物品。
6. 收集後返回確認進度。

成功判斷: 下步升級清楚，也知道材料來源。

疑難排解: 建議與別人帳號不同？規劃會考慮最高 SOL3 Phase。 預覽角色缺資料？部分預覽計畫接近推出時才提供。
