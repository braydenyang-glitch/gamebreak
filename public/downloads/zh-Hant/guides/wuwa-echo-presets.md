## 保存並比較聲骸預設

鳴潮 · 鳴潮・聲骸裝配 · PC / Mobile / Console

來源核對: 2026-10-15. 尚未實測；來源核對不代表最新版本已驗證。 · 尚未實測；來源核對不代表最新版本已驗證。
聲骸預設記載於版本 2.1

在 Echo Preset 保存 Current Setup，套用其他配置前先比較。

開始之前: 擁有聲骸，且可使用聲骸裝配。

1. 開啟共鳴者的聲骸裝配介面。
2. 選右下 Echo Preset 圖示。
3. 選 Current Setup，再選 Save As Preset。
4. 使用能說明用途的名稱。
5. 選已存預設，展開屬性比較。
6. 確定要讓目前共鳴者使用該配置時才按 Apply。

成功判斷: 預設名稱出現，套用的配置符合預期。

疑難排解: 屬性不對？套用前比較預設與 Current Setup。 以為會換武器？此功能保存聲骸配置，武器需另行檢查。

保存預設只是保留配置，不代表該配裝最佳。
