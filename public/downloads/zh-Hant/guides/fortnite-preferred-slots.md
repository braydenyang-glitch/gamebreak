## 讓裝備欄保持固定順序

功能記載於 v17.20

在 Settings → Game → Preferred Item Slots 指定物品類型。

開始之前: 可開啟 Game 設定，且使用支援的 Battle Royale 模式。

1. 開啟 Settings，選 Game 分頁。
2. 找到 Preferred Item Slots，選 Configure。
3. 將常用武器類型分配到喜歡的欄位。
4. 留一格放治療或其他消耗品，再套用設定。
5. 對局中保留空欄，拾取符合類型的物品。
6. 確認位置後，再練習對應的切換武器操作。

成功判斷: 符合類型的拾取物進入預定欄位。

疑難排解: 背包已滿？文件記錄的自動分配至少需要一個空欄。 消耗品移到右側？也檢查 Auto-Sort Consumables to Right。

這是依類型分配欄位，不是保存特定槍枝清單；選單不同時請核對安裝版本。
