採集點・於 1.3 推出

在背包或共鳴者頁選擇突破材料，再開啟 Collection Spots。

開始之前: 支援追蹤的突破材料，且能進入該區域。

1. 找出預計突破需要的材料。
2. 在背包或共鳴者頁選擇材料圖示。
3. 選 Collection Spots，讓地圖顯示位置。
4. 前往收集；該處採集完後，可追蹤下一個位置。

成功判斷: 地圖顯示材料採集位置。

疑難排解: 沒有 Collection Spots 時，確認區域開放與材料提供的來源選項。

此功能出自官方 1.3 版本說明。能追蹤位置不代表材料立刻可取得，也不代表所有區域已解鎖。
