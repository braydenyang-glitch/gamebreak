Java Edition 1.19+・儲物箱船

在船外潛行並互動即可開啟箱子。

開始之前: 已有儲物船，以及安全岸邊。

1. 把裝貨的船開到安全岸邊。
2. 乘坐時開啟背包，查看船內箱子。
3. 把需要物品移到背包空格。
4. 在船外潛行並與船互動，再開啟儲存空間。
5. 先搬完剩餘貨物，再決定是否拆船。

成功判斷: 不拆載貨船就把物品移到背包或岸上儲存。

疑難排解: 貨物掉出來：破壞船會讓內容物掉落。 豬布林生氣：開啟或破壞儲物船可能激怒牠們。

本篇限定 Java，未驗證其他版本的操作與行為。
