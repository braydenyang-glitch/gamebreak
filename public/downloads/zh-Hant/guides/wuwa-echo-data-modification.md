數據改造記載於版本 2.3

開啟 Terminal → Data Bank → Data Modification。

開始之前: Modifier 與未強化的五星聲骸。

1. 開工具前先選共鳴者與屬性目標。
2. 開啟 Terminal → Data Bank → Data Modification。
3. 選符合條件、未強化的五星聲骸。
4. 選提供的第一主屬性目標。
5. 確認前檢查選擇與費用。
6. 查看修改後聲骸；修改會自動上鎖。

成功判斷: 聲骸顯示選定的第一主屬性。

疑難排解: 聲骸不能選？查看稀有度與是否已強化。 想改副屬性？文件記錄此功能改第一主屬性。
