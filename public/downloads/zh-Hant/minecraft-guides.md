高爐・一般生存機制

開始之前: 五個鐵錠、三塊平滑石、一個熔爐與適用燃料。

攜帶鐵鎬，利用座標探索主世界深層。不要把舊版 Y=11 建議當成所有版本的通則。

開始之前: 鐵鎬、食物、火把、方塊，以及返回基地的路線。

1. 出發前記錄基地座標。
2. Java 版按 F3 查看 XYZ；Bedrock 版在世界的遊戲設定中啟用「顯示座標」。
3. 攜帶鐵鎬；石鎬不適合用來採集鑽石。
4. 以階梯或可原路返回的方式下降，注意落差與岩漿。
5. 探索深層地形及埋藏方塊。1.18 之後的分布使更低處有更多鑽石礦，且暴露於空氣中的礦石較少。
6. 用鐵鎬採集找到的鑽石礦，並在補給用盡前返回。

成功判斷: 找到鑽石礦、用適當工具取得掉落物，並能沿路返回。

疑難排解: 核對世界生成版本，不要只看洞穴表面。任何路線都不保證找到鑽石。
