# GameBreak — Delta Force

烽火地帶是撤離模式：路線、裝備預算與撤離時機同樣重要。先用負擔得起的裝備完成小目標，熟悉一張地圖，再追求高價物資。

## 槍枝、彈藥與交戰距離

建立可以反覆使用的入門配置，不只看槍價或稀有度。

PC・烽火地帶（Operations）。以地區版本說明為準；不套用全面戰場規則。

1. 開啟槍枝與彈藥詳情，確認口徑相容及畫面上的穿透資訊。
2. 在改槍介面一次比較一個配件，保留負擔得起的簡單配置。
3. 開戰前找掩體與退路，不要在空地試用不熟悉的武器。
4. 出擊後記錄問題來自彈藥、控槍或站位，下次只調整該項。

兩種模式的平衡可能不同；此處不宣稱固定擊殺門檻或最強配裝。

## 組成有計畫的小隊

依照幹員說明與標記，分配偵察、支援及共同撤離時機。

PC・烽火地帶（Operations）。以地區版本說明為準；不套用全面戰場規則。

1. 閱讀所選幹員的 Operations 能力說明，不直接套用全面戰場定位。
2. 約定誰偵察前方、誰在隊友搜索容器時看守後方。
3. 在對局外設定 Operations 標記輪盤，用簡短訊息回報威脅、物資與移動。
4. 使用 Morse 等偵察幹員時，只回報能力實際偵測到的資訊，並保留退路。
5. 短暫分開前先訂集合點；全隊彈藥或醫療物資不足時一起撤離。

能力範圍與冷卻可能改動，不要假設偵測效果永久存在。

## 保護出擊預算，整理戰利品

區分倉庫、隨身裝備與任務材料，避免一次失敗就無法再出發。

PC・烽火地帶（Operations）。以地區版本說明為準；不套用全面戰場規則。

1. 備用裝備留在倉庫，只把本次目標需要的裝備放進配置。
2. 放入貴重物品前，先確認安全箱的容納規則及空間。
3. 持有裝備券時，先看套裝內容與限制，再決定是否額外花費哈夫幣。
4. 撤離後保留需求材料、補齊必需品，只賣掉確定多餘的物資。

撤離失敗可能損失攜帶物資；安全箱仍有物品與使用權限制。

## 先讀地圖，再規劃搜刮路線

用官方地圖預先規劃，再於實際對局確認撤離條件。

PC・烽火地帶（Operations）。以地區版本說明為準；不套用全面戰場規則。

1. 在官方工具選擇正確地圖與難度，先專注熟悉一張地圖。
2. 找出目標與附近標記，規劃短路線，不為搜刮橫跨整張地圖。
3. 進入對局後查看撤離清單、條件及剩餘時間；可行時準備第二方案。
4. 受傷、聽到槍聲或背包滿時重新評估；小目標完成就可以撤離。

地圖與撤離規則會改變；舊路線不保證出口當下開放。

## 設定 PC 音效、道具操作與標記

這裡是遊戲設定，不是控制台指令；每次改一項，試用後決定保留或還原。

PC・烽火地帶（Operations）。以地區版本說明為準；不套用全面戰場規則。

1. 戴耳機時到 Settings → Audio → HRTF，比較方向音效後再決定。
2. 在 Control & Combat 查看支援道具的 Quick Throw、Hold、Default 操作。
3. 若明亮閃光不舒服，可試用 Flash Protection；它改變畫面呈現，不會取消閃光效果。
4. 在戰鬥外設定標記輪盤，下次出擊前練習威脅與移動標記。

官方 PC 更新曾列出這些設定；名稱及可用性可能因地區版本或輸入裝置不同。

## 把部門任務連到黑站升級

依照真正缺少的物資規劃升級，不因配方解鎖就盲目生產。

PC・烽火地帶（Operations）。以地區版本說明為準；不套用全面戰場規則。

1. 選一個部門任務，出擊前讀完達成條件。
2. 查看下一項補給站或黑站需求，列出還缺少的材料。
3. 比較黑站工作台、藥劑台或防具台配方，優先處理自己會用的物資。
4. 在遊戲確認成本與完成時間，領取成品後更新材料清單。

賽季任務、使用權與配方可能改動；這是規劃方法，不是保證賺錢的方法。
