# GameBreak — Wuthering Waves

《鳴潮》是在索拉里斯展開的開放世界動作RPG。你扮演漂泊者，與共鳴者同行，透過技能、時機與換人形成戰鬥節奏。探索取得素材與聲骸，再把資源集中投入角色和武器養成。

## 學會共鳴者真正的戰鬥節奏

先練短流程，再學長連招。

手動戰鬥練習；依目前共鳴者技能文字。

1. 從指南的成長之路找到技能教學，先讀目前共鳴者的共鳴技能、共鳴解放與共鳴回路。
2. 先練一段普攻，再練防守反應；觀察敵人動作與閃避或逆勢回擊提示，不要同時亂按所有按鈕。
3. 觀察共鳴回路量表，讀懂如何累積與消耗；依官方指南練該角色流程，不同角色沒有通用的一套循環。
4. 為觸發變奏與延奏效果換人前，確認協奏準備狀態；比較有無該換人安排的短練習，每次只改一個步驟。

敵人招式與角色機制都有例外；這是練習流程，不是經實測的最高傷害連招。

## 讓隊友、武器與聲骸配合

使用角色專屬指南，並建立可重複的比較方式。

組隊規劃與聲骸預設；不提供當期強度排名。

1. 先選想作為核心的角色打法，再加入能配合的隊友；若生存是主要問題，先補回復或保護。
2. 從終端進入攻略入口，或使用庫洛官方指南；選對共鳴者，查看武器、聲骸、升級優先度與隊友建議。
3. 安排換人前讀清楚延奏效果與受益角色，也檢查武器和聲骸是否符合你分配的職責。
4. 更動前把目前聲骸配置存為預設，比較顯示屬性，再用同一場戰鬥測試，避免拿不同條件判斷配裝。

攻略入口可能有不同作者與更新時間；推薦配置是參考，不代表一定最適合你的帳號。

## 規劃真正需要的素材路線

串起養成畫面、採集點與領獎成本。

資源規劃；不承諾掉落數量或正在生效的加成。

1. 選一項升級，記下缺少素材與貨幣；先分清世界採集物和挑戰獎勵，再安排路線。
2. 支援追蹤的採集素材可從背包或共鳴者畫面開啟，選採集點並追蹤附近一組，避免沒有目標地亂跑。
3. 領取獎勵前看清結晶波片消耗與獎勵種類，把它花在缺少的養成項目，不要假設所有挑戰掉落相同素材。
4. 完成預定路線後檢查背包，夠下一次升級就停；將星聲預算與日常刷素材的決定分開。

過去雙倍活動不是永久掉落率；實際成本與加成要看目前領獎畫面和正在開放的公告。

## 探索地區時不再迷失路線

善用傳送點、地圖分層與開放資訊。

一般區域探索；不宣稱包含完整收集物地圖。

1. 先跟隨當前主線開放目標地區，順路啟用共鳴信標，之後就能快速返回。
2. 可用時打開地圖的地區指南，查看玩法開放條件，不必猜測為何活動或設施進不去。
3. 檢查地圖分層、目標高度或入口；平面位置很接近，也可能在不同區域或樓層。
4. 換區前先完成一段小路線：任務目標、附近採集點與返回點；目前進不去的地方先記下，達成條件後再來。

不同故事階段開放地點不同，地圖工具能協助找路，不能跳過任務條件。

## 使用貨幣前先確認喚取

閱讀目前規則，能試用時先試用角色。

喚取閱讀；連結中的活動是歷史範例，不是即時時程。

1. 開啟目前喚取及詳情，確認目標、結束時間、票券種類，以及確認畫面的兌換成本。
2. 讀取該卡池保底與繼承規則；角色、武器、新手或特殊慶典喚取不一定完全相同。
3. 若當期活動提供初聲先覺等試用，先體驗共鳴者攻擊與操作，確定喜歡打法再決定抽取。
4. 設定停止預算並記錄支出，保留資源給真正優先目標；舊公告只代表過去規則，不代表該卡池仍開放。

這裡不保證結果，也不建議付費；所選喚取的規則以遊戲內目前詳情為準。

## 把探索變成穩定的帳號進度

推進故事，同時培養一支真正能用的核心隊伍。

新手養成原則；不宣稱目前等級上限或終局最佳配裝。

1. 閱讀下一段主線前置條件，再從指南選可進行的任務；新地區推出不代表所有帳號都能立即進入。
2. 優先養少數核心共鳴者及武器，在遊戲內確認缺少的升級材料，不要一次平均投入所有新角色。
3. 收集時查看資料塢與聲骸畫面，分清收集進度、單一聲骸養成等級與裝備效果。
4. 戰鬥變難時回到技能教學並查角色指南，判斷下一步應該是練習、武器養成、技能還是聲骸配置。

攻略建議與帳號解鎖條件可能調整，採用舊清單或預設最高等級前，先讀目前畫面。
