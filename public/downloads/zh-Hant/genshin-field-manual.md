# GameBreak — Genshin Impact

《原神》結合開放世界探索與可即時換人的動作戰鬥。元素戰技、爆發與反應讓隊友互相配合。先推進故事、開啟傳送點、養好一支可用隊伍，再追求全收集或完美聖遺物。

## 先練會一種明確的元素反應

先看懂自己的攻擊施加什麼元素，再學長循環。

一般元素戰鬥；不提供實測傷害或當期強度排名。

1. 閱讀兩名角色的戰技與爆發，確認哪個動作真正施加元素。
2. 對適合的敵人先施加水、火、冰或雷，再用風元素攻擊觀察擴散。
3. 觀察元素圖示與反應名稱，放慢重做，分辨哪次操作觸發反應。
4. 再加入移動與防禦手段，最後才延長連段，並留一些體力閃避。

敵人免疫與角色特殊機制可能改變結果；這是入門練習，不是通用最佳循環。

## 讓每個隊伍位置都有任務

可用隊伍需要清楚的操作順序與生存方式。

初期組隊流程；裝備建議仍需依角色判斷。

1. 先用已有角色選一種主要輸出方式，記下關鍵戰技或爆發。
2. 用反應、增益、治療或護盾補足隊伍。這是規劃方法，不是固定陣容。
3. 先檢查武器等級、重要天賦與合適的聖遺物主詞條，再考慮重養整隊。
4. 同一關卡測兩次，每次只改生存、充能或傷害中的一個弱點。

五星物品或熱門隊伍不一定符合你的角色與養成進度。

## 把樹脂用在看得見的升級

從缺少素材倒推，不要沒有目標地刷。

素材規劃；實際消耗及獎勵倍率以遊戲內為準。

1. 打開下一階角色或武器升級，列出缺少素材與摩拉。
2. 查看素材來源，刷武器素材前先核對秘境顯示的開放日。
3. 將自然恢復的原粹樹脂用來解決目前瓶頸，領獎前確認消耗。
4. 達到目標就停止該項刷取，再定下一個目標；脆弱樹脂另外規劃。

不要把花原石回復樹脂當成必要步驟；此計畫可用免費自然恢復完成。

## 有紀錄地探索一個區域

結合傳送點、任務追蹤與地圖分層。

低劇透探索流程，並非完整全收集路線。

1. 先開附近錨點與神像，再追蹤一個任務或收集目標，別同時跑太多遠點。
2. 找不到神瞳時，對照官方提瓦特互動地圖的區域與地下分層。
3. 神瞳共鳴石圈出區域後，查看高處、地下及地形後方；圓圈不是精確定位點。
4. 將確認取得的項目標記，未解謎題先記錄；長距離攀爬或游回前確認體力。

部分收集物需要任務或地區機制；地圖有標記不代表路線已開放。

## 花資源前先看懂祈願

分清卡池、規則與自己的資源上限。

規則閱讀與預算；不預測抽取結果或推薦當期卡池。

1. 打開想抽的那個祈願，閱讀詳情、當期物品與結束時間。
2. 兌換原石前，確認按鈕消耗糾纏之緣、相遇之緣或其他指定資源。
3. 查看該類祈願的歷史與保底規則，不要混用角色、武器與特殊卡池的假設。
4. 先設定最多花多少資源，試玩可用的角色試用，到達上限就停止。

保證某稀有度不一定保證指定物品；以目前遊戲內詳情為準。

## 冒險等階卡住時怎麼查

將帳號進度與角色、武器升級分開檢查。

一般等階排查；解鎖條件以帳號目前顯示為準。

1. 經驗看似卡住時，查看冒險等階與任務欄是否有冒險等階突破任務。
2. 挑戰前檢查目前隊伍的武器、重要天賦、聖遺物及生存手段。
3. 準備好後完成必要突破任務；累積冒險閱歷會在完成後計入。
4. 若大世界難度不舒服，查看是否可調整世界等級，先改善一個瓶頸再重試。

帳號等階不能取代裝備養成，難度提升可能暴露隊伍不足。
