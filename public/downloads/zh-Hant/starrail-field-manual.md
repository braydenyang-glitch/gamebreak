# GameBreak — Honkai: Star Rail

《崩壞：星穹鐵道》是搭乘星穹列車展開的回合制宇宙冒險。依敵方弱點、共用戰技點與角色職責組隊。主線開放目的地，角色等級、光錐、行跡與遺器則幫隊伍面對更難的戰鬥。

## 用戰技點與弱點掌握戰局

適合手動戰鬥的基本練習流程。

一般回合制戰鬥；各角色可能有特殊規則。

1. 選目標前先看敵人弱點圖示。對應屬性的攻擊可削減韌性；特殊護盾與關卡規則要另外讀。
2. 查看行動順序與共用戰技點，先規劃接下來誰需要戰技，再決定目前角色的動作。
3. 一般普攻多可回復戰技點，戰技通常會消耗；強化普攻與角色例外應以技能說明為準。
4. 終結技就緒時，先判斷它要解決傷害、回復還是保護。手動練一場，記下失敗是生存、選錯目標或缺戰技點造成。

特殊角色或模式可能改變基本規則，以技能文字與戰鬥教學為準。

## 組出能穩定打完的隊伍

從職責、正確型態與相容裝備出發。

角色型態、光錐命途與一般組隊。

1. 先選主要傷害來源並說清楚輸出方式；無法生存時加入治療或保護，再補上能配合該打法的輔助。
2. 想使用光錐被動前，先確認佩戴者符合命途；稀有度高不代表不相容的效果也會生效。
3. 在隊伍畫面確認型態。三月七與開拓者有不同型態；某命途攻略不能直接套到另一型態，可用隊伍預設保存。
4. 打一場熟悉戰鬥觀察戰技點。若所有人每回合都想放戰技，先調整行動安排，再投入更多裝備素材。

這是組隊方法，不是當期強度榜；部分關卡需要不同生存或輸出策略。

## 為下一次升級刷素材

把養成畫面變成一張短刷取清單。

素材規劃；不預設掉落量或當前體力上限。

1. 開啟一項角色、光錐或行跡升級，記下缺少素材；先選近期用得到的提升，不必一次刷滿全部。
2. 從素材來源或星際和平指南的生存索引進入，確認擬造花萼、凝滯虛影、侵蝕隧洞或歷戰餘響的獎勵與條件。
3. 領獎前確認畫面上的開拓力消耗，達到預定素材量即可停手；額外補充道具留到有明確需求再用。
4. 若養成指南的總素材量不符預期，檢查行跡篩選；只計算推薦行跡可能漏掉你想升的項目。

關卡與提前體驗入口依進度和現行規則而定，請讀取鎖定提示，不要只照舊截圖。

## 找對路線，處理任務卡點

先看導航與任務狀態，再判斷是不是地點出錯。

任務導航與互動衝突；避免故事劇透。

1. 一次追蹤一項任務，出發前閱讀目標與地點；標記很近卻到不了時，先檢查地圖樓層。
2. NPC無法互動時讀取衝突提示；其他進行中的任務可能占用該角色，先完成提示的任務再返回。
3. 把鎖定地區與活動當成進度檢查，依指南或任務畫面的現行開放條件決定下一步。
4. 無法向帕姆領取開拓等級獎勵時，檢查是否被列車任務占用；處理後再回來領取。

部分任務會刻意改變地區或NPC狀態，單純重登無法取代必要的故事步驟。

## 花星瓊前讀懂躍遷

分清卡池種類、查看紀錄並設定上限。

躍遷閱讀與預算管理；不提供當期卡池推薦。

1. 打開所選躍遷的查看詳情，閱讀該卡池的提升物品、結束時間、消耗貨幣與保底規則。
2. 角色活動躍遷、光錐活動躍遷與常駐躍遷需分開計算，不要把帳號所有抽數相加推估一個卡池的保底。
3. 從躍遷→查看詳情→紀錄確認；新紀錄可能延遲顯示，舊紀錄不在可見列表中也不代表保底歸零。
4. 抽取前先決定停止點並確認票券種類；保留資源給真正想要的目標，不要只因倒數結束就抽。

本頁不保證特定結果，也不建議付費；個別卡池規則以遊戲內目前詳情為準。

## 為下一階均衡做好準備

聚焦主線與帳號進度的檢查清單。

主線推進與一般準備；以目前入口提示優先。

1. 先看下一任務需求與任務列表中的均衡試煉，不要假設所有鎖定活動都有相同等級門檻。
2. 挑戰困難試煉前檢查主隊角色等級、光錐與常用行跡；除了主輸出，也補強不足的生存手段。
3. 從關卡入口確認真正解鎖途徑；凝滯虛影等素材關卡可能有故事條件或提前體驗選項，以目前提示為準。
4. 進度提升後查看指南的新入口並領取可領的開拓等級獎勵，接著只選一項隊伍養成目標。

帳號等級不能取代隊伍準備，本清單不保證通過特定終局模式。
