# GameBreak — Fortnite

Battle Royale 結合搜裝、戰鬥與安全區移動。先選擇可建造模式或 Zero Build，再於當前島嶼練習固定的物品配置與落地流程。

## 在適合的距離與位置交戰

用簡單武器分工並保留回掩體的路線；只有支援建造的模式才練建造。

Battle Royale／Zero Build；以當前模式與島嶼為準，不混用 Reload 或 Save the World。

1. 從實際撿到的武器中，分配近距離與較遠距離用途。
2. 開火前找掩體，判斷靠近時是否會暴露給其他方向的敵人。
3. 用熟悉的欄位切換武器，在安全空檔補彈及恢復。
4. 可建造 BR 先練一種防禦建築；Zero Build 則先找下一個天然掩體。
5. 失敗後只挑一項調整：站位、距離選擇或操作靈敏度。

這是練習流程，不是賽季武器排名；可用武器依模式與更新不同。

## 讓小隊撐過救援階段

先溝通安全救援計畫，避免所有隊友一起進入危險位置。

Battle Royale／Zero Build；以當前模式與島嶼為準，不混用 Reload 或 Save the World。

1. 選擇共同落地區，改變計畫時先通知隊友。
2. 有人倒地時，先確認掩體與敵方壓力，再開始救援。
3. 隊友被淘汰時，查看當前重啟卡及重啟車提示，不把它當成一般救援。
4. 一人負責救援，其他人看守入口；風暴讓路線不可行時立即改變計畫。
5. 救援後分配可用裝備，重新集合再開戰。

連結的 v8.30 是重啟系統的歷史介紹；舊計時與裝備數值不作為目前指令。

## 讓每個物品欄都有用途

依下一次交戰整理：可用武器、恢復用品，以及當前模式提供的工具。

Battle Royale／Zero Build；以當前模式與島嶼為準，不混用 Reload 或 Save the World。

1. 把近距離與遠距離武器放在固定欄位，避免交戰時還在找武器。
2. 撿另一把武器前，檢查彈藥，以及它是否補足現有配置缺少的用途。
3. 盡量保留恢復用品並閱讀使用條件，不假設每種道具恢復相同資源。
4. 可建造 BR 跨空地前檢查建材；Zero Build 則優先考慮掩體與可用工具。

Epic 開發者頁說明類 BR 的背包架構，不保證當前掉落池或所有模式的欄位規則。

## 在風暴逼迫前先轉點

用當局地圖規劃，不死背舊賽季路線；準備主要路線與附近備案。

Battle Royale／Zero Build；以當前模式與島嶼為準，不混用 Reload 或 Save the World。

1. 選落地區時準備附近替代點；人太多就及早調整。
2. 完成初步搜裝後開地圖，查看當前安全區及風暴倒數。
3. 選有掩體與第二出口的地形移動，不必對每個遠方槍聲都追擊。
4. 每次安全區變化後重看地圖，先告訴隊友下一站，再繼續搜裝。

地名、移動道具與載具會輪替；此方法不保證固定生成或安全落地。

## 調整操作與聲音視覺化

讓操作在自己的裝置上清楚好按；別人的靈敏度只能當測試起點。

Battle Royale／Zero Build；以當前模式與島嶼為準，不混用 Reload 或 Save the World。

1. 開選單進入 Settings，依裝置選鍵盤箭頭或手把分頁。
2. 檢查切槍、互動與移動按鍵，重要操作不要放在難按的位置。
3. 在 Audio 試用 Visualize Sound Effects 並套用，可顯示部分聲音的提示。
4. 做短時間練習，每次只調整一個靈敏度或畫面設定，再比較差異。

這是設定而非作弊指令；聲音提示不能完整追蹤敵人，操作分頁也依平台不同。

## 讓短時間遊玩也有明確任務進度

選能完成的任務、確認條件，再查看成果；經驗值與獎勵領取資格是兩件事。

Battle Royale／Zero Build；以當前模式與島嶼為準，不混用 Reload 或 Save the World。

1. 開啟當前任務列表，選一項符合準備遊玩之 Battle Royale 模式的目標。
2. 規劃落地前先讀行動、地點、物品條件與期限。
3. 在正常遊玩中完成任務，不犧牲隊伍安全與轉點時間。
4. 結束後確認進度，領獎前查看通行證的等級、前置與擁有權條件。

經驗值速度、任務與獎勵會變動，不保證瞬間升級、固定經驗值或免費付費獎勵。
