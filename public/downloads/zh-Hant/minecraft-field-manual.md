# GameBreak — Minecraft

Minecraft 是方塊建造沙盒。生存模式把採集、合成與探索連在一起。先建立小型庇護所和穩定食物來源，再安排深礦與遠行。本指南適用一般原版玩法；先確認世界是 Java 還是 Bedrock。

## 第一晚：小而安全的起點

目標是能住的庇護所與基本合成，等白天再擴張。

原版生存模式・Java 與 Bedrock；差異另註。已查閱來源，未實機測試。

1. 採集原木並轉成木材，將物品欄四格合成格都放入木材，製作工作台。
2. 放置工作台，利用配方書製作木棒與木鎬；先看缺哪些材料，再去採集。
3. 天黑前圍起小空間並封住入口。有火把時照亮室內，裝飾可以之後再做。
4. 快捷列放食物與備用方塊。日出時先觀察外面；白天不代表所有危險都消失。

第一晚的掩體只是暫時住處；改善照明與入口後，才當作長期基地。

## 盾牌、距離與撤退路線

先用防禦創造出手機會，別每次都硬換血。

原版生存模式・Java 與 Bedrock；差異另註。已查閱來源，未實機測試。

1. 用六塊木材與一個鐵錠做盾牌，放入副手欄，主手便能拿武器。
2. Java 按住「使用物品」舉盾；Bedrock 持盾時潛行。先練熟自己版本的操作再戰鬥。
3. 面向攻擊方向；盾牌主要保護前方，多面受敵時應退後。
4. 保留回到掩體的路，補充食物再接戰。擋下攻擊後調整位置，不要留在包圍中。

盾牌不能阻擋所有傷害，斧頭也能使盾牌失效；Java 與 Bedrock 的戰鬥節奏不同。

## 從石器到第一批鐵

用對應工具挖礦，再把鐵原礦煉成可用鐵錠。

原版生存模式・Java 與 Bedrock；差異另註。已查閱來源，未實機測試。

1. 用木鎬取得鵝卵石，先做石鎬再挖鐵礦；木鎬無法採得鐵礦資源。
2. 工作台外圈放八塊鵝卵石、中央留空，製作熔爐。
3. 把鐵原礦放入熔煉欄，煤炭等燃料放入燃料欄，完成後從輸出欄拿鐵錠。
4. 依下一個目標使用首批鐵錠：鐵鎬用來挖鑽石礦，盾牌用來探索；基地留一把備用工具。

請核對所在版本的配方書；這是原版生存配方，並非模組加工或最佳挖礦高度表。

## 探索後也能找到回家的路

出發前記下目的地，利用座標規劃回程。

原版生存模式・Java 與 Bedrock；差異另註。已查閱來源，未實機測試。

1. 記下基地 X、Y、Z。Java 可透過 F3 查看；Bedrock 在世界設定開啟「顯示座標」。
2. X、Z 是水平方向，Y 是高度。另記洞口座標，回到地表更容易。
3. 一般指南針在主世界指向世界出生點；基地若在別處，就以記錄的座標為準。
4. 帶食物、照明與方塊。第一次選短路線，岔路用一致方式標記，物資不足前就返程。

一般指南針無法可靠導航地獄與終界；本篇以主世界旅行為準。

## 在練習世界使用第一批指令

先試簡單、看得懂的指令，和正式生存世界分開。

原版生存模式・Java 與 Bedrock；差異另註。已查閱來源，未實機測試。

1. 建立練習世界。Java 開啟指令、Bedrock 開啟作弊；多人世界還需要世界或伺服器擁有者授權。
2. 開啟聊天輸入 /help。先讀自己遊戲顯示的提示，不要直接貼另一版本的指令。
3. 有權限時，兩版都可用 /give @s minecraft:torch 16 給執行玩家十六支火把；@s 指執行者。
4. 用 /time set day 將練習世界設為白天。一次只改一項，確認結果後再試下一條。

Bedrock 世界開過作弊後，即使關閉也無法再取得成就。Java 物品資料與 Bedrock 元件語法不能互換。

## 和朋友建立共用基地

先確認版本與簡單分工，再各自出發。

原版生存模式・Java 與 Bedrock；差異另註。已查閱來源，未實機測試。

1. 先對版本：原版 Java 與 Bedrock 無法直接互連。確認相容版本及伺服器要求的資源包。
2. Java 可用「多人遊戲／新增伺服器」，或同網路 LAN；Bedrock 可透過好友邀請加入。
3. 建議分工：一人找食物、一人收建材、一人準備照明；分開前分享基地座標。
4. 共用箱加標示並存放備用工具。使用稀有材料做個人作品前，先約定哪些資源共用。

伺服器規則與附加內容可能改變玩法；一般成員不會自動擁有管理員權限或所有指令。
