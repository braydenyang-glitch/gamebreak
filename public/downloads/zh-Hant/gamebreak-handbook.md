## 元素反應

原神 · 戰鬥

搭配不同元素，改變攻擊效果。

相容的元素接觸時會產生元素反應。例如，火與水可以觸發蒸發，火與冰可以觸發融化。這些反應會提高觸發該反應的攻擊傷害。

施加元素的順序很重要。切換角色前，先閱讀技能說明並留意敵人身上已有的元素。反應隊伍需要穩定施加元素，並非放入四種不同元素就足夠。

- 蒸發: 火 + 水
- 融化: 火 + 冰
- 觀察重點: 目標身上的元素圖示

## 冒險等階與世界等級

原神 · 進度

帳號進度與世界難度是不同的系統。

冒險等階代表帳號進度，會解鎖系統、任務與挑戰。它與個別角色的等級不同。累積冒險閱歷可以提升冒險等階。

世界等級會影響大世界中的敵人與獎勵。部分提升需要完成突破任務。若提升世界等級後戰鬥突然變難，先檢查主力隊伍的裝備與培養進度。

- 冒險等階: 帳號進度
- 世界等級: 大世界的難度與獎勵
- 角色等級: 另外培養與提升

## 原粹樹脂

原神 · 資源

領取部分挑戰的獎勵時會消耗樹脂。

原粹樹脂會隨時間恢復，可用來領取地脈之花、秘境與首領等活動的獎勵。完成挑戰與領取獎勵是兩個不同的步驟。

花費樹脂前，先決定要取得哪一種培養素材。開啟素材的來源資訊，找到對應挑戰。實際消耗請查看遊戲內獎勵畫面；本文不假設上限或恢復速度永遠不變。

- 資源: 原粹樹脂
- 用途: 領取部分挑戰獎勵
- 遊戲內確認: 消耗量與剩餘樹脂

## 聖遺物部位與屬性

原神 · 裝備

主屬性要符合角色的用途。

聖遺物會提高角色屬性，部位包括生之花、死之羽、時之沙、空之杯與理之冠。每件都有主屬性，以及通常稱為副屬性的其他數值。

套裝可以提供額外效果，但屬性仍需要適合角色。更換前先比較新舊兩件。閱讀角色技能，確認主要效果是依攻擊力、生命值、防禦力或其他屬性計算。

- 裝備: 聖遺物

## 韌性與弱點擊破

崩壞：星穹鐵道 · 戰鬥

使用對應弱點的屬性攻擊來削減韌性。

韌性是敵人生命值上方的額外量條。符合弱點屬性的攻擊通常會削減它。清空量條會觸發弱點擊破，可能延後敵人行動，並依擊破攻擊的屬性施加效果。

部分敵人會鎖定韌性，或擁有多層韌性；部分角色技能也會改變一般規則。若對應弱點的攻擊似乎無效，請檢查敵人資訊及目前戰鬥效果。

- 所屬對象: 敵人
- 基本方法: 使用敵人列出的弱點屬性攻擊
- 不同於: 生命值

## 全隊共用的戰技點

崩壞：星穹鐵道 · 戰鬥

消耗戰技點前，先想好下一個角色的行動。

戰技點是全隊共用的資源，許多戰技都會消耗它。一般普通攻擊通常會恢復一點，許多戰技則會消耗一點。不同技能可能有不同消耗、額外產生戰技點，或使用特殊資源。

選擇行動前先看共用的點數。如果下一位隊友需要使用治療或輸出戰技，現在可以考慮普通攻擊。請以目前技能說明為準，不要假設每個角色都遵守同一套規則。

- 資源: 全隊共用
- 常見恢復方式: 一般普通攻擊
- 例外: 角色專屬技能機制

## 合成與配方書

Minecraft 創世神 · 基礎

從配方確認所需材料及排列方式。

在 Java 與 Bedrock 中，合成會把材料製成新物品。背包內有小型合成格；放置並使用工作台就能使用更大的合成格。工作台可用木材合成。

開啟配方書並選擇想製作的物品，就能查看所需材料與排列方式。紅色材料提示代表缺少材料。請使用自己版本的配方書，不要假設所有版本的配方都完全相同。

- 版本: Java 與 Bedrock
- 起步順序: 原木 → 木材 → 工作台
- 工具: 遊戲內配方書

## 床與重生點

Minecraft 創世神 · 生存

遠行前，先設定安全的返回位置。

Java 與 Bedrock 的新世界都有世界出生點。在主世界使用床，可以設定個人重生點。使用後請留意確認訊息。

搬動床不會自動移動重生點。請在新的安全位置再次使用床。若舊重生點無法使用，死亡後可能會回到世界出生點，因此也要記下基地位置。

- 版本: Java 與 Bedrock
- 床的適用範圍: 主世界
- 記得: 搬動床後再次使用

## 讀懂座標

Minecraft 創世神 · 探索

出發前先記下基地的 X、Y、Z。

座標用 X、Y、Z 三個數值表示位置。Y 代表高度，X 與 Z 則表示世界中的水平位置。記錄座標能幫助你返回基地或與朋友會合。

Java Edition 可以在 F3 除錯介面查看座標，介面配置可能隨版本改變。Bedrock Edition 有「顯示座標」世界設定。請依照實際遊玩的版本操作。

- Java: F3 除錯介面
- Bedrock: 世界設定中的「顯示座標」
- Y 值: 高度

## 生命值、飢餓值與食物

Minecraft 創世神 · 生存

除了愛心，也要注意食物量表。

在一般 Java 與 Bedrock 生存模式中，愛心表示生命值，雞腿圖示表示飢餓值。活動會消耗食物值。食物耗盡可能造成傷害，結果會依難度而異。

進食會恢復飢餓值；在一般世界規則下，足夠飽足有助於自然回血。挖礦或旅行前請帶好食物。若生命值的運作方式不同於一般生存世界，請檢查難度與遊戲規則。

- 版本: Java 與 Bedrock
- 愛心: 生命值
- 雞腿圖示: 飢餓值

## 通緝星數與搜索範圍

## 建築材料

Fortnite 堡壘之夜 · 戰鬥
