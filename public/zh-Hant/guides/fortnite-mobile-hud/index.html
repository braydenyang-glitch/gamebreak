找到並測試手機 HUD 編輯工具

一次調整一個觸控介面按鈕。

Fortnite 堡壘之夜 · 大逃殺・原生手機觸控介面

尚未實測 · 發行商手機 HUD 編輯器入口說明

快速解答

個人頭像 → 選單 → HUD Layout Tool 可開啟版面編輯器。

開始之前

使用觸控的手機版遊戲。

步驟

  1. 點右上個人頭像。
  2. 開啟左下的三條線選單。
  3. 在選單靠近底部選 HUD Layout Tool。
  4. 使用編輯器選項，先調整一個難按的控制項。
  5. 依目前提示套用版面。
  6. 在安靜區域測試，按鈕遮住視野時再調整。

能按到調整後按鈕，也看得到戰況。

設定頁不對？回個人選單找 HUD Layout Tool。 多個操作更難用？恢復舊版面，再一次只改一項。

支援文章確認了入口路徑；一次改一項是編輯建議，編輯器名稱可能不同。
