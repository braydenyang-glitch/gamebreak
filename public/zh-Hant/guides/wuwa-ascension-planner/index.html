規劃一名共鳴者的下一步培養

用內建計畫找到角色各裝備缺少材料。

鳴潮 · 鳴潮・一般大世界與選單

尚未實測 · 共鳴者養成規劃記載於版本 2.7

快速解答

開啟 Terminal → Resonators → 培養規劃器，查看各模組。

開始之前

可使用角色培養規劃器，且有想提升的角色。

步驟

  1. 開啟 Terminal → Resonators，進入培養規劃器。
  2. 選想培養的共鳴者。
  3. 查看共鳴者、武器、聲骸與技能模組。
  4. 選一項可達成的下步升級，不必一次刷全部。
  5. 用材料來源捷徑找到缺少物品。
  6. 收集後返回確認進度。
