Fortnite 堡壘之夜 · 大逃殺

尚未實測 · 大逃殺・選單尚未實測

快速解答

開啟遊戲選單 → Report → Submit a report → A bug，送出前檢查截圖。

開始之前

問題仍在遊戲中可見，最好在消失前回報。

步驟

  1. 開啟遊戲的三條線選單，選擇 Report，再選 Submit a report。
  2. 選 A bug 與最接近的原因；都不符合時選 Other。
  3. 檢查截圖，必要時重拍，再按 Continue 與 Accept。

回報流程顯示確認。

截圖沒拍到時，在安全情況下重現問題。

Epic 建議在問題可見時回報；送出回報不代表錯誤已修復。
