快速解答

Modifier 與未強化的五星聲骸。

步驟

  1. 開工具前先選共鳴者與屬性目標。
  2. 開啟 Terminal → Data Bank → Data Modification。
  3. 選符合條件、未強化的五星聲骸。
  4. 選提供的第一主屬性目標。
  5. 確認前檢查選擇與費用。
  6. 查看修改後聲骸；修改會自動上鎖。
