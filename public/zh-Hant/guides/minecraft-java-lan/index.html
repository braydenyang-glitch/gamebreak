讓附近朋友加入 Java 世界

建立本地連線，分清與 Bedrock 多人模式的差異。

Minecraft 創世神 · Java

尚未實測 · Java Edition・開放區域網路

快速解答

載入 Java 世界，選 Open to LAN，檢查訪客設定後開放區域網路。

開始之前

同一區域網路中的 Java 玩家，且版本相容。

步驟

  1. 使用 Java 版，確保所有玩家連上同一個區域網路。
  2. 載入世界，開啟遊戲選單並選 Open to LAN。
  3. 檢查加入玩家的模式與指令權限，再啟動 LAN 世界。
  4. 請其他 Java 玩家查看 Multiplayer 列表。

朋友找到並加入 LAN 世界。

看不到場次時，確認版本種類、遊戲版本與區域網路存取。

請使用相同遊戲版本。Java LAN 與 Bedrock 邀請流程不同；本篇不是網際網路伺服器設定教學。
