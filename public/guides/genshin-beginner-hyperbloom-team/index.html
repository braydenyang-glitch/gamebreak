Build a beginner Hyperbloom team

Give each teammate a clear job before spending upgrade materials.

Genshin Impact · Overworld · standard Hyperbloom

Unverified · Standard Dendro reactions · documented in Version 3.0

Quick answer

Combine Hydro and Dendro to create Dendro Cores, then hit those cores with Electro to trigger Hyperbloom.

Before you start

Owned characters able to apply Hydro, Dendro and Electro.

Steps

  1. Choose one owned character for each element: Hydro, Dendro and Electro.
  2. Read their skills and identify which attacks apply those elements.
  3. Apply Hydro and Dendro to a normal enemy to create a Dendro Core.
  4. Use an Electro attack that reaches the core and watch for Hyperbloom.
  5. For a comfortable beginner team, use the remaining slot for healing or shielding if the first three characters do not provide it.

You can produce Hyperbloom and explain each teammate’s job.

No Hyperbloom? Check that a core formed and the Electro attack actually reached it.

The fourth-slot suggestion is GameBreak’s beginner planning advice. This is not a current endgame ranking or a Lunar-Bloom guide. Special character talents can change reactions.
