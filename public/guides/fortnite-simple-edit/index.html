Try Simple Edit on your own build

Learn the assisted edit setting without memorizing tile selections.

Fortnite · Battle Royale · building playlists that allow Simple Edit

Unverified · Publisher Simple Edit help

Quick answer

Enable Simple Edit in Game settings and look at the part you want to change.

Before you start

A supported building playlist and a build you can edit.

Steps

  1. Open Settings and select the Game tab.
  2. Turn Simple Edit on.
  3. Review Tap to Simple Edit: on uses a tap; off uses a held input.
  4. Place a wall in a quiet location.
  5. Aim at the intended section and use your Edit control.
  6. Inspect the opening and try another section to learn the preview.

An intended edit completes using the assisted selection.

No building available? Zero Build is not the place to practise this. Option unavailable in a match? Epic excludes competitive modes from this feature.

Source checked; not gameplay tested. Use the current in-game prompts if controls differ.
