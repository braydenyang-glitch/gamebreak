Make a separate save before troubleshooting

Keep a recovery point for your story progress.

Grand Theft Auto V · Story mode

Unverified · Story Mode · build untested

Quick answer

Use the phone’s Quick Save and choose a separate slot before testing a mission workaround.

Before you start

Story Mode with saving available.

Steps

  1. In Story Mode, open the in-game phone and select Quick Save.
  2. Choose a separate save slot; keep your earlier save.
  3. After saving, load the new slot if the workaround calls for a reload.

A separate save entry exists with the expected progress.

If saving is unavailable, wait until the current activity ends.

This is a recovery step, not a guaranteed mission fix. It does not apply to GTA Online.

Rockstar Support · Quick Save workaround
