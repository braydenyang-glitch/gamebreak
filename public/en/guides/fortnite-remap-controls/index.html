Change one uncomfortable control

Make a small control change and test it before changing more buttons.

Fortnite · Battle Royale · keyboard or controller

Unverified · Publisher control configuration help

Quick answer

Choose the keyboard or controller tab in Settings.

Before you start

Access to Settings and a keyboard or supported controller.

Steps

  1. Select Battle Royale in the lobby so its settings are available.
  2. Open the menu and select the settings gear.
  3. Choose the keyboard-arrow icon or the gamepad icon.
  4. On PC with a controller, check the selected controller configuration.
  5. Change one uncomfortable action and apply the setting.
  6. Test that action in a quiet area and keep a note of the old binding.

The intended button performs the action comfortably.

Keyboard tab missing on Switch? That tab is not supported there. Wrong options showing? Return to the intended game mode and input-device tab.

Source checked; not gameplay tested. Use the current in-game prompts if controls differ.
